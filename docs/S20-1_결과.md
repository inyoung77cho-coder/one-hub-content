## 효과 (예상)

- 지배적 비용이던 **`/api/etf/quote` 개별 N회(실측 49회)** → **시장별 배치 ~2회 + 30초 캐시 dedup**.
- `pwa-dashboard` 3→1, `accuracy` 2→1, `fx`·`etf-report` 다회→1.
- 회귀 안전장치: 배치 미배포/실패 시 개별 폴백, 총자산 덧셈은 `lib/ledger` 한 곳 유지(새 키 없음), 값 계산 로직 불변.

## 검증

- `bash scripts/verify_s19.sh` → **FAIL=0** (원장 회귀 항목 포함).
- `npm run build`(webpack) → **통과**.
- ⚠ **합격선 API 호출 수·응답시간은 로그인 상태 브라우저 실측이 필요**(카카오 게이트). 배포 착륙 후 아래로 측정:
  ```js
  const es = performance.getEntriesByType('resource').filter(e => e.name.includes('/api/'));
  console.log(es.length, Math.round(Math.max(...es.map(e => e.responseEnd))));
  ```
  - 합격선: `/pwa` ≤30, `/pwa/today` ≤30, 마지막 응답 ≤2.5초.
