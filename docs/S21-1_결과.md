# S21-1 결과 — 부동산 브리핑 첫 화면에서 분리

작업일 2026-09-01 · Claude Code

## 한 것 (`pages/pwa/today.js`, 프론트만 = 지시서 A안)
- 마운트 `load()` 안에 있던 `/api/pwa/re/briefing`(단독 4,987ms) + 그 앞의 `/api/pwa/re/complexAreas` 호출을 **제거**.
- 부동산은 별도 탭(view===1)이라, 두 호출을 **부동산 탭 진입 시 1회만** 실행하는 `loadReBrief()` + `useEffect([view])`(reBriefLoadedRef 가드)로 이전.
- 자산 변경(`onehub-assets-change`) 시 ref 를 리셋해, 등록/수정 후 부동산 탭을 다시 열면 최신 지역으로 재로드.
- 상단 3행 요약은 briefing 값을 안 쓰므로 그대로 즉시 완성. 오늘(view 0) 부동산 확장행은 `myLeaderGapPct`(=reBrief 의존)가 없으면 기존 폴백대로 "내 단지 포지션 →" 링크로 표시(S20-3 방어 그대로).

## 검증
- `bash scripts/verify_s19.sh` → **FAIL=0**.
- `npm run build`(webpack) → **통과**.
- ⚠ 합격선(/pwa/today 화면 완성 ≤2.5초, API ≤30회, 상단 3행이 briefing 전에 완성)은 **로그인 브라우저 실측** 필요:
  ```js
  const es = performance.getEntriesByType('resource').filter(e => e.name.includes('/api/'));
  console.log('calls', es.length, 'lastEnd', Math.round(Math.max(...es.map(e => e.responseEnd))));
  ```
  - 기대: 오늘 진입 시 `/api/pwa/re/briefing` 미호출 → lastEnd 가 4.9초 → 2.5초 이하로. 부동산 탭 전환 시 briefing 로드·정상 표시.

## 비고
- 지시서 B안(서버 사전생성)은 미착수 — A안만으로 오늘 화면에서 briefing 4.9초가 빠진다. 실측이 2.5초를 못 넘기면 그때 :5002 briefing 계산부(무엇이 5초를 쓰는지) 확인 후 사전생성 진행 권장.
