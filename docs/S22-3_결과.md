작업일 2026-09-02 · Claude Code

## 왜
자산관리 앱의 진짜 해자는 누적 시계열. 기기 변경·캐시 삭제에 곡선이 통째로 날아가면 안 된다.

## 한 것
1. **적립 지점 확대** — 기존 오늘·자산·AI(index) 탭 외에 **ETF·부동산·AI advisor** 진입 시에도 적립. 공용 backstop `lib/dailySnapshot.js` `ensureDailySnapshot()`(getLedger→recordSnapshot, 세션당 1회·같은 날 병합)을 `pages/pwa/etf.js`·`realestate.js` 마운트에 배치, `ai-advisor.js` 는 이미 부르던 getLedger 결과로 직접 적립. → **어느 탭으로 들어와도 그날 1건 보장**.
2. **서버 동기화(핵심)** — `lib/syncManager.js` `SYNC_KEYS` 에 `onehub_asset_history_A`·`onehub_asset_history_B` 추가 → `/api/user/state` 로 push/pull. **다른 기기에서 로그인해도 곡선이 따라온다.**
3. **자산군별 저장** — `lib/assetHistory.js` 는 이미 `{ date, total, stock, etf, realty, cash }` 로 적립(기존 충족).
4. **화면 최소** — 종합자산 스파크라인 이미 존재(`assets.js` Sparkline).
