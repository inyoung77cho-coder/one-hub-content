## 0. ★ 새 채널을 만들지 마십시오

이미 **머니더버니** 채널이 있습니다. 거기에 재생목록 셋을 붙이십시오.

새 채널을 파면 세 가지를 잃습니다.

1. **기존 구독자** — 지금 몇 명이든, 0에서 다시 시작하는 것과는 다릅니다
2. **알고리즘 이력** — 유튜브가 이 채널을 누구에게 보여줄지 학습한 결과가 리셋됩니다
3. **브랜드 일관성** — 머니더버니의 약속이 *"AI의 판단을 실패까지 포함해 투명하게 공개한다"* 입니다. **시리즈 B(혼자 만드는 자산 앱)가 정확히 그 약속의 실행**입니다. 다른 채널에 두면 둘 다 약해집니다

재생목록만 나누면 됩니다. 한 채널, 세 재생목록.

```
① 서현동 이야기        시리즈 A · 유입
② 혼자 만드는 자산 앱   시리즈 B · 주간 리포트 · 잔류
③ ONE·HUB 사용법       시리즈 C · 전환
```

**재생목록 설명은 한 줄씩만** 쓰십시오. 길면 아무도 안 읽습니다.

| 재생목록 | 설명 한 줄 |
|---|---|
| 서현동 이야기 | 분당 한 동네에서 자산을 다시 배운 기록 |
| 혼자 만드는 자산 앱 | 매주 무엇을 만들고 무엇을 틀렸는지 |
| ONE·HUB 사용법 | 3분이면 시작합니다 |

## 1. 업로드 전 채널 설정 — 한 번만

```

    "주식·부동산·ETF를 한 화면에서 보는 앱을 혼자 만들고 있습니다."
□ 채널 링크에 one-hub.kr 추가
□ 기본 업로드 설정 → 시청자층: "아동용 아님"
    ← 이걸 "아동용"으로 두면 댓글이 막히고 추천에서 사라집니다
□ 기본 언어: 한국어 / 국가: 대한민국
□ 재생목록 3개 생성 (위 표대로)
```

## 2. 1주차 실행 순서

**월~화 · 촬영 준비**

```
□ 시연용 계정 생성 (★ 본인 계정으로 찍지 마십시오)
□ 시연 계정에 종목 2~3개 직접 입력 + 손절선·목표가 설정
□ 홈 화면 추가를 아직 안 한 상태로 되돌려 둘 것
    ← U1의 핵심 장면입니다. 이미 추가돼 있으면 못 찍습니다
□ 폰 알림 끄기 · 방해금지 모드
□ 화면 녹화 테스트 1분 (소리 들어가는지)
```

**수 · 촬영 40분**

`docs/유튜브_사용법_U1-U2_대본.md`의 U1을 그대로 따라가십시오. 초 단위 타임라인과 나레이션 전문이 있습니다.

```
□ 0:00 후킹 — 앱 세 개 여는 장면
□ 0:20 주소 타이핑 (자동완성 쓰지 말고 한 글자씩)
□ 0:50 카카오 로그인 (화면 가림)
□ 1:10 ★ 홈 화면 추가 — 아이폰·안드로이드 둘 다
□ 2:00 온보딩 5단계 빠르게
□ 3:00 ★ 판단 버튼 한 번
□ 3:30 다음 편 예고
```

**목 · 편집 60분**

```
□ 자막 — 버튼 이름은 전부 자막으로도
□ 숫자 마스킹 확인 (한 프레임도 빠짐없이)
□ 길이 4분 ±1분
```

**금 · 발행**

```
□ 제목      ONE·HUB 3분 만에 시작하기 — 설치도 가입 양식도 없습니다
□ 설명란    아래 3절 참조
□ 재생목록  ONE·HUB 사용법
□ 시청자층  아동용 아님
□ 종료화면  다음 영상 + 구독
□ 고정 댓글 "막히신 부분 있으면 댓글 주세요. 그게 다음 편 소재가 됩니다."
□ 이야기 탭 주간 회차에 한 줄 남기기 (새 채널 만들지 말 것)
```

**금~일 · 지인 초대**

4절 문안대로. **한 번에 30명에게 보내지 마십시오.** 5~6명씩 나눠 보내고, 첫 그룹의 반응을 보고 문장을 고치십시오.

```

세 군데를 열어야 내 자산이 얼마인지 알 수 있었습니다.
그게 불편해서 직접 만들고 있는 앱입니다.

이 영상에서는 처음 시작하는 3분을 그대로 보여드립니다.
설치도, 가입 양식도 없습니다.

▶ 앱 바로가기  https://one-hub.kr/pwa
▶ 로그인 없이 먼저 보기  https://one-hub.kr/estimate

00:00 왜 만들었나
00:20 브라우저에서 열기
00:50 카카오 로그인
```

## 4. 지인 초대 문안

**★ 앱 링크를 먼저 보내지 마십시오.** 로그인 화면부터 만나면 대부분 닫습니다. 영상 → 앱 순서입니다.

### ① 첫 메시지 (1:1 카톡)

```
자산 관리 앱 하나 만들고 있어요.
주식·부동산·ETF를 한 화면에서 보는 건데,
3분이면 시작합니다.

사용법 영상 먼저 찍었어요 — [영상 링크]

봐주시고 이상한 데 있으면 알려주시면 고맙겠습니다.
```

**보내지 말아야 할 것**: "대박이에요", "꼭 써보세요", "출시했습니다". 부담을 줍니다. 지금은 출시가 아니라 **봐달라는 부탁**입니다.

### ② 반응이 오면 (앱 링크)

```
고맙습니다.
https://one-hub.kr/pwa

카카오 로그인 한 번이면 되고,
종목 하나만 넣어보시면 감이 오실 거예요.
```

### ③ 3일 뒤 (딱 한 번만)

```
어디서 멈추셨어요?
```

**이 한 문장만 물으십시오.** "어땠어요?" "좋았어요?"는 "좋았어요"라는 답만 돌아옵니다. 아무것도 못 얻습니다.

그리고 답이 오면 **반박하지 마십시오.** 설명하고 싶어지는 지점이 바로 고쳐야 할 지점입니다. 받아 적기만 하십시오.

### 단톡방에 보낼 때

개인 메시지 먼저, 단톡은 나중입니다. 단톡에 먼저 뿌리면 아무도 안 누르고, 그다음 개인 메시지도 안 먹힙니다.

## 5. 1주차가 끝나면 볼 숫자

AI 탭 → 정비소 → 가입 깔때기(S30-9)에서 확인합니다.

| 관문 | 30명 기준 목표 |
|---|---|
| 영상 조회 | — |
| `/estimate` 조회 (`from=youtube`) | 측정 시작 |
| 가입 | 30 |
| 온보딩 완료 | 24 |
| 보유 1건 입력 | 20 |
| **첫 판단** | **15** ← 가장 중요 |
| 7일 재방문 | 10 |

**첫 판단 15명이 성공 기준입니다.** 판단이 없으면 심판석도 주간 리포트도 작동하지 않고, 그 사람들은 이 앱의 유일한 차별점을 한 번도 못 봅니다.

첫 주에 이보다 훨씬 낮게 나와도 정상입니다. **숫자보다 "어디서 멈췄는지"가 중요합니다.**

## 6. 하지 말 것

- **주 2편** — 두 달 안에 무너집니다. 주 1편입니다
- **1화부터 발행** — 스토리는 5화(삼성전자·하이닉스)부터입니다. 검색 유입이 가장 큰 편이 첫 편이어야 합니다
- **완벽한 편집** — 4분짜리에 8시간 쓰면 2편을 못 냅니다
- **수익률 자랑** — 규제선에 가깝고, 브랜드 약속과도 어긋납니다
- **사용법만 연속 발행** — 새 사람이 안 옵니다. 사용법과 스토리를 번갈아
- **본인 계정으로 촬영** — 한 프레임이면 끝입니다
