## 진단

`pages/pwa/today.js`는 이미 "카드 나열"이 아니라 "할 일 중심 5블록" 설계였다(파일 상단 주석 [N3] 참고). 그러나 조인영님이 지적한 두 지점은 실제로 비어 있었다.

1. **② 오늘의 통합 판단**: 관망/필터 상태를 텍스트로만 설명하고, 매수 후보가 있을 때조차 다음 행동으로 이어지는 버튼이 없었다. "왜 걸렀나" 링크만 있고 "뭘 사도 되는지 보러 가기" 링크가 없었다 — 그래서 후보가 있는 날에도 "그래서 뭘 해야 하지?"가 남는다.
2. **④ 나 vs AI**: 이미 채점이 끝난 승부가 있어도 "N건 채점 중"이라는 관리자용 문구만 보여줬다. `lib/verdictLedger.js`의 `computeShowdown()`이 승/패/무와 실제 수익률(%)을 이미 계산해주는데 이 페이지에서는 쓰지 않고 있었다(전체 리포트 탭에서만 사용 중).

## 변경 내용

### 🔴 통합 판단 → 핵심 요약 + 행동 유도
- 섹션 제목 옆에 상태 배지 추가: `매수 후보 N`(초록) / `필터 N`(회색) / `관망`(연회색) — 카드를 안 열어도 오늘 상태를 한눈에.
- 매수 후보가 있으면(`cands.length > 0`) **주 CTA 버튼**을 항상 노출: "매수 후보 N종목 확인하기 →" → `/pwa?tab=recommend`.
- 기존 "무엇을 왜 걸렀나 →" 링크는 유지(필터가 있을 때).
- 자산군 교차 인사이트(insight) 블록은 기존 그대로 유지.

### 🔴 나 vs AI 더 생동감
- `computeShowdown(mine, 3)` → 없으면 `computeShowdown(mine, 7)` 순으로 이미 채점된 승부를 조회.
- 채점된 승부가 있으면 스코어보드 형태로 표시: `🏆 내 판단 승` / `💀 AI 승` / `⚖️ 무승부` + 나·AI 각각의 실제 수익률(%). 전체 리포트 탭(`나 vs AI` 상세)과 동일한 색·이모지 규칙을 재사용해 두 화면이 다른 말을 하지 않도록 함.
- 채점된 승부가 없을 때는 기존 "N건 채점 중" 문구를 그대로 유지(회귀 없음).
