# S22-7 결과 — 종합자산 위계 전환

작업일 2026-09-02 · Claude Code

## 문제
가장 큰 숫자(총자산 57.87억)가 손댈 수 없는 실거주(47.20억)를 포함해, 화면 위계가 실제 판단 대상(운용 10.67억)과 반대였다.

## 한 것 (`pages/pwa/assets.js` — 자산 지도 카드 순서만, 보유/추천 탭 구조 불변)
1. **운용자산을 헤드라인으로** — 실거주가 있으면 `운용자산(opTotal)` 을 크게, 그 아래 `총자산` + `🔑 실거주 · 못 파는 자산` 을 작은 줄로. 실거주가 없으면 종전대로 총자산만 크게(운용=총자산).
2. **오늘의 한 수** — 가장 급한 신호 하나만. 현재는 목표 배분 이탈(S22-4)이 유의미할 때 "🎯 오늘의 한 수 — ETF가 목표보다 +N%p 많습니다 · 리밸런싱 보기 →". 없으면 침묵.
3. **총자산 곡선** — 스파크라인(S22-3) 기존 유지.
4. **"읽기 전용 지도예요" 문구 삭제** — 매일 열 이유를 부정하는 문장 제거("상세 확인·수정은 각 자산 페이지에서 이어집니다"만 유지).
