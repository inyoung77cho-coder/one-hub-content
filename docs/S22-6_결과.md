## 한 것
1. **알림 채널 분리(사용자/운영자)** — `pages/api/notifications.js` 프록시가 운영자 source(`job_monitor`·`disk_guard`·`proc_guard`·`healthcheck`·`version_watch` 등)를 **사용자 알림함에서 제거**. `?admin=1` 이면 전부(운영자 화면용). 실측 source 분포: telegram(사용자) 295 · job_monitor(운영자) 2 · queue_release(사용자) 1.
2. **주간 리포트 발송(서버)** — `real_estate/scripts/weekly_verdict_report.py`(신규):
   - 동기화된 `user_state`(accounts.db)에서 판단 원장(onehub_ai_vs_me·onehub_duel_decisions)·총자산 곡선(onehub_asset_history)을 읽어 지난주 요약 작성.
   - **웹푸시 재사용** — auto_trade `ops_log.record_notification`(알림함 insert + push_bot 웹푸시), 사용자 채널 `source="weekly_report"`, `action_url="/pwa/record"`.
   - **판단 0건 주 미발송** — week_summary 가 None → skip(빈 알림 = 구독 해지 방지).
   - **크론** `0 0 * * 1`(월 00:00 UTC = **월 09:00 KST**).
   - DRY-RUN 검증: 현재 `user_state` 0행(아직 서버 동기화된 판단 데이터 없음) → "대상 0명·발송 0명"(0건 가드 정상 동작). 사용자가 앱을 열어 상태가 동기화되면(SYNC_KEYS에 판단·자산곡선 포함) 자동 활성.
