## 1. 사용법 영상 시리즈 — 5편

**서현동 이야기(스토리 7편)와는 다른 시리즈입니다.** 스토리는 감정과 서사, 사용법은 화면과 손가락입니다. **재생목록을 나누십시오.**

| 편 | 제목 | 가이드 섹션 | 길이 | 우선 |
|---|---|---|---|---|
| **U1** | 3분 만에 시작하기 | 1장 전체 | 4분 | ★ 먼저 |
| **U2** | 증권 계좌 없이 쓰는 법 | 유형 B·C | 5분 | ★ 먼저 |
| **U3** | 매일 3분 루틴 | 3장 | 5분 | |
| **U4** | 화면 다섯 개 둘러보기 | 4장 | 6분 | |
| **U5** | 부동산·듣기만 쓰는 법 | 유형 D·E | 5분 | |

### 왜 U2가 두 번째인가

**신규 유입의 대다수가 증권 계좌를 연동하지 않습니다.** "연동 안 해도 다 됩니다"를 초반에 말하지 않으면 그 사람들은 U1만 보고 떠납니다. 이건 시뮬레이션에서 가장 크게 나온 이탈 지점입니다.

### 사용법 영상의 원칙 — 스토리 영상과 다릅니다

1. **화면이 주인공입니다.** 나레이션은 화면을 설명하는 역할이지 그 반대가 아닙니다.
2. **실시간 조작을 보여주십시오.** 편집으로 건너뛰지 말고 손가락이 움직이는 걸 그대로. 초보자는 "어디를 누르는지"가 궁금합니다.
3. **한 편에 한 가지만.** 욕심내면 아무것도 안 남습니다.
4. **자막 필수.** 버튼 이름은 반드시 자막으로도 나와야 합니다.
5. **숫자는 전부 마스킹.** 스토리 영상과 같은 원칙입니다.

### 편별 시연 순서

**U1 · 3분 만에 시작하기**
```
0:00  후킹 — "3분이면 됩니다. 설치도 가입 양식도 없어요"
0:20  브라우저에서 one-hub.kr/pwa 열기 (실제 조작)
0:50  카카오 로그인 (화면 가림 처리)
1:10  ★ 홈 화면에 추가 — 아이폰/안드로이드 둘 다 시연
2:00  온보딩 5단계 — 빠르게, "모르면 건너뛰세요" 강조
3:00  ★ 마지막 판단 버튼 한 번 — "이게 시작점입니다"
3:30  다음 편 예고
```
**핵심 한 문장**: "종목 하나만 넣고 버튼 한 번 누르면 끝입니다."

**U2 · 증권 계좌 없이 쓰는 법**
```
0:00  후킹 — "계좌 연동, 안 하셔도 됩니다. 기능 차이 없습니다"
0:30  ＋ 버튼으로 주식 직접 입력 (실제 조작)
1:30  ETF 직접 입력 — 티커 넣는 법
2:20  ★ 손절선·목표가 정하기 — "이걸 정해야 알려줍니다"
3:20  다음 날 오늘 화면에 뜨는 모습
4:20  "연동하면 뭐가 편한가" 30초 — 강요하지 않기
```
**핵심 한 문장**: "직접 넣어도 판단 기록·성적표·주간 리포트 다 똑같이 됩니다."

**U3 · 매일 3분 루틴**
```
0:00  후킹 — "이 앱은 오래 보라고 만든 게 아닙니다"
0:30  아침에 오늘 화면 여는 실제 모습
1:10  판단 버튼 누르기 — 세 가지 경우 시연
2:20  조치가 없는 날 화면 — "이게 정상입니다"
3:20  🎧 전체 듣기 — 화면 꺼도 나오는 것 보여주기
4:20  월요일 성적표 미리보기
```
**핵심 한 문장**: "매일 버튼 하나. 그게 전부입니다."

**U4 · 화면 다섯 개 둘러보기**
```
편당 1분씩 — 오늘 · 자산 · AI · 듣는 경제 · 이야기
각 화면에서 "여기서 할 수 있는 것 하나"만 시연
스와이프와 하단 탭의 차이 명확히
```

**U5 · 부동산·듣기만 쓰는 법**
```
0:00  후킹 — "주식 안 하셔도 쓸 데가 있습니다"
0:30  내 단지 등록 → 포지션 보기
2:00  ★ 지금 팔면 손에 쥐는 금액
3:20  듣는 경제 — 언어·테마 고르기, ☆ 단어 담기
4:30  "매일 안 오셔도 됩니다" — 정직하게
```

### 발행 순서와 스토리 시리즈의 관계

```
1주차  U1 (사용법)        ← 채널 개설 + 지인 초대 시작
2주차  스토리 5화 (삼성전자)  ← 검색 유입
3주차  U2 (연동 없이)
4주차  스토리 2화 (ETF 중복)
5주차  U3 (매일 루틴)
6주차  스토리 1화 (세 자산)
…
```

**사용법과 스토리를 번갈아** 올리십시오. 사용법만 올리면 새 사람이 안 오고, 스토리만 올리면 온 사람이 못 씁니다.

## 2. 주차별 업데이트 — 운영 틀

매주 무엇이 바뀌었는지 알리는 자리입니다. **이야기 탭의 주간 회차와 같은 자리에 실으십시오** — 새 채널을 만들지 마십시오.

### 매주 쓰는 템플릿

```markdown
## N주차 (YYYY-MM-DD ~ MM-DD)

### 이번 주 바뀐 것
- (사용자가 체감하는 표현으로. "S31-2 완료"가 아니라 "로그인 없이 단지 시세를 볼 수 있게 됐습니다")

### 왜 바꿨나
- (한 줄. 어떤 불편에서 왔는지)

### 이번 주 숫자
- 가입 N명 · 첫 판단 M명 · 7일 재방문 K명
- 공개 도구 조회 N건 → 가입 전환 M건

### 다음 주에 할 것
- (하나만. 여럿 적으면 안 지킵니다)
```

### 소재는 어디서 뽑나

**전부 이미 앱과 저장소 안에 있습니다. 새로 조사하지 마십시오.**

| 소재 | 출처 |
|---|---|
| 이번 주 바뀐 것 | `docs/S**-**_결과.md` 의 "한 것" 항목 |
| 사용자 숫자 | AI 탭 → 정비소 → 가입 깔때기(S30-9) |
| 엔진 개선 | `engine_changes` 원장(S28-1) |
| 이번 주 판단 성적 | AI 탭 심판석 |
| 부동산 소식 | 주간 부동산 현황(S24-11) |

### 개발 용어를 쓰지 마십시오

결과 문서의 문장을 그대로 옮기면 아무도 안 읽습니다. **한 번 번역하십시오.**

```
✘  S30-1 allHoldings 통합으로 source 필드 도입
✔  직접 입력한 종목도 이제 오늘 화면에 나옵니다

✘  S31-1 공개 API 레이트리밋 적용
✔  로그인 없이 단지 시세를 볼 수 있게 됐습니다
```

### 주차 리포트의 진짜 목적

숫자 자랑이 아닙니다. **"이 앱이 살아 있고, 내 불편이 실제로 고쳐진다"는 신호**입니다. 지인 30명 단계에서 이게 가장 강력한 잔류 이유입니다.

그래서 **바꾼 게 없는 주에는 없다고 쓰십시오.** "이번 주는 안정화만 했습니다"가 억지로 만든 항목보다 낫습니다.

## 3. 가이드 문서 유지 규칙

기능이 바뀌면 **아티팩트 가이드를 고쳐야** 합니다. 안 고치면 가이드가 거짓말이 됩니다.

### 어느 스프린트가 가이드의 어디를 바꾸나

| 다가올 변화 | 가이드에서 고칠 곳 |
|---|---|
| **S31-2** 공개 적정가 도구 | 1장에 "가입 전에 먼저 써보기" 추가 · 유형 D 첫 줄 |
| **S31-4** 은퇴·인출 | **유형 F 전체 교체** — 지금은 "준비 중"이라고 쓰여 있음 |
| **S31-6** 계좌 개설 제휴 | 유형 A·B에 한 줄. 제휴 표기 필수 |
| **S31-7** 계좌별 보기 | 4장 자산 화면 설명 |

**유형 F는 특히 잊지 마십시오.** 지금 가이드에 "인출 계획 기능은 준비 중입니다"라고 정직하게 써뒀는데, S31-4가 끝나면 그 문장이 틀린 말이 됩니다.

### 갱신 절차

1. 스프린트 결과 문서를 읽고
2. 위 표에서 해당 줄을 찾아
3. 아티팩트를 고쳐 다시 발행(같은 링크 유지)
4. 주차 리포트에 "가이드도 갱신했습니다" 한 줄

## 4. 지인 30명에게 보낼 때

**보내는 순서가 중요합니다.**

```
1) 가이드 링크 + "3분이면 됩니다" 한 줄
2) (읽었다는 반응이 오면) 앱 링크
3) 3일 뒤 "어디서 막히셨어요?" 한 번만
```

**앱 링크를 먼저 보내지 마십시오.** 로그인 화면부터 만나면 대부분 닫습니다.

### 물어볼 것은 하나뿐입니다

"좋았어요?"는 답이 안 나옵니다. 대신:

> **"어디서 멈추셨어요?"**

이 질문만 하십시오. 그리고 답이 오면 **반박하지 말고 받아 적으십시오.** 설명하고 싶어지는 지점이 바로 고쳐야 할 지점입니다.

### 30명 목표 숫자 (S30 funnel로 측정)

| 관문 | 목표 |
|---|---|
| 가입 | 30 |
| 온보딩 완료 | 24 (80%) |
| 보유 1건 입력 | 20 |
| **첫 판단** | **15** ← 가장 중요 |
| 7일 재방문 | 10 |

**첫 판단 15명이 이 단계의 성공 기준입니다.** 판단이 없으면 심판석도 주간 리포트도 작동하지 않고, 그 사람들은 이 앱의 유일한 차별점을 한 번도 못 봅니다.
