### S20-3 · 오늘 탭 1화면 재구성 — P1, 구조 변경이라 마지막

**사용자가 정의한 목적**: "자주 봐야 하는 새 정보로 **자산의 처분 유무를 확인**하고 현재 자산을 이해하는 관문. 정보 입력과 가독성·활용도가 높아야 한다."

**현재 상태**: 1화면이 포트폴리오 대결 카드. '오늘의 할 일 · 주식'은 스크롤 3화면 아래이고 내용은 "오늘은 특별히 할 일이 없어요 · 관망"뿐. 처분 판단의 근거(목표가 잔여·손절 근접·다음 트리거)는 자산 › 보유 탭에만 있다.

**작업 — `pages/pwa/today.js` 상단 3행 신설**

| 행 | 내용 | 데이터 출처 |
|---|---|---|
| 1 | 총자산 1줄 + 전일 대비 + 마지막 갱신 시각 | `lib/ledger.js` `getLedger` (이미 호출 중) |
| 2 | **오늘 조치할 종목** — 목표가 도달/손절 근접만 0~3개 | `deriveUrgency(p).rank <= 2` — `components/shared/KisHoldingsCard.js` 에서 import |
| 3 | 어제 대비 AI 변화 한 줄 | `pages/pwa/index.js` 의 `aiFreshness` 로직 재사용(공용 함수로 빼는 게 좋다) |

- 2행이 비면 "오늘 조치 없음"으로 끝내지 말고 **근거와 함께** — 예: "5종목 모두 유지 구간 · 손절선 최근접 −6.1%".
- **대결 카드는 AI 탭으로 이동**. 오늘 탭에는 결과가 나온 날만 배너 한 줄.
- 자산군 확장: ETF 리밸런싱 이탈, 부동산 대장 대비 포지션도 '오늘 조치' 후보에 넣는다(현재 오늘 탭은 주식만 다룬다 — 유료화 축이 3개 통합 종합자산인데 통합이 안 보인다).
- "🗞 봇이 오늘 보낸 뉴스 · {오늘}" 아래 항목이 실제로는 08-24~08-28자다. **항목별 실제 날짜를 표기**하고, 오늘 것이 없으면 "오늘 신규 없음 · 최근 08-28"로 정직하게.

**주의**: `today.js` 는 964줄이다. 기존 섹션을 지우지 말고 **순서 재배치 + 상단 3행 신설**로 접근할 것. 삭제는 대결 카드 하나뿐.

1. **줄바꿈** — 저장소 전체가 CRLF다. `.gitattributes` 에는 `*.sh text eol=lf` 만 있다(셸 스크립트가 CRLF로 바뀌면 Git Bash·서버에서 `syntax error: unexpected end of file` 로 죽는다. 실제로 `verify_s19.sh` · `health.sh` 가 그랬다). `.js` 편집 시 줄바꿈을 바꾸지 말 것 — 바꾸면 236개 파일이 통째로 변경된 것처럼 잡힌다.
2. **빌드는 반드시 webpack** — `package.json` 의 `"build": "next build --webpack"` 을 지우지 말 것. Turbopack 프로덕션 빌드는 하이드레이션이 깨져 PWA 전체가 무반응이 된다.
3. **총자산 덧셈은 `lib/ledger.js` 안 한 곳뿐** — 어떤 화면도 자산을 직접 더하지 않는다. 새 localStorage 키를 만들지 않는다.
4. **동시 작업** — 2026-08-31 기준 다른 세션이 `pages/pwa/etf.js` 등 ETF 화면을 작업 중이었다(`2b2418c`, `da92cfa`). 작업 시작 전 `git pull --rebase`.
