# STEP 1·2 — 폰 녹화 준비와 첫 사용자 화면 만들기

> 작성 2026-09-13 · U1 촬영 직전 단계
> 이 문서는 **폰만 들고 따라 하는 문서**입니다. 여기까지 끝나면 바로 녹화로 넘어갑니다.

---

# STEP 0 · 먼저 정할 것 하나

**아이폰입니까, 안드로이드입니까?**

아래는 둘 다 적어뒀습니다. 본인 것만 보시면 됩니다. 다만 한 가지는 미리 알아두십시오.

| | 아이폰 | 안드로이드 |
|---|---|---|
| 화면 녹화 | 기본 제공 | 기본 제공 |
| **터치 지점 표시** | **없음** | **있음 (개발자 옵션)** |
| 홈 화면에 추가 | 사파리에서 가장 확실 | 크롬 |

**터치 표시가 안드로이드에만 있습니다.** 사용법 영상에서 "어디를 눌렀는지"가 보이는 건 큰 차이입니다. 안드로이드가 있으시면 **U1은 안드로이드로 찍는 것을 권합니다.**

---

# STEP 1 · 화면 녹화 켜기

## 1-A. 아이폰

**① 녹화 버튼 꺼내기** (한 번만)
```
설정 → 제어 센터 → "화면 기록" 옆 ＋ 눌러 추가
```

**② ★ 마이크 끄기** (가장 중요)
```
화면 오른쪽 위에서 아래로 쓸어내려 제어 센터 열기
→ 화면 기록 버튼(◉)을 꾹 길게 누르기
→ 아래 "마이크" 아이콘이 빨간색이면 눌러서 끄기 (회색 = 꺼짐)
```

**마이크가 켜져 있으면 주변 소음이 다 들어갑니다.** 목소리는 나중에 따로 녹음합니다.

**③ 녹화 시작·중지**
```
시작: 제어 센터 → ◉ 누르면 3초 카운트 후 시작
중지: 화면 왼쪽 위 빨간 시간 표시 → 탭 → "중지"
저장: 사진 앱에 자동 저장
```

## 1-B. 안드로이드

**① 녹화 버튼 꺼내기**
```
화면 위에서 두 번 쓸어내려 빠른 설정 전체 열기
→ 연필/＋ 아이콘 → "화면 녹화"를 위쪽으로 끌어다 놓기
```

**② ★ 소리 설정**
```
화면 녹화 버튼 탭 → 설정 창이 뜸
→ 소리: "소리 없음" 선택        ← 반드시
→ 화면 터치 표시: ★ 켜기        ← 사용법 영상에 중요
→ 시작
```

**③ ★ 터치 지점 표시 (더 선명하게)**

빠른 설정의 "터치 표시"가 흐리면 개발자 옵션 쪽이 더 잘 보입니다.

```
설정 → 휴대전화 정보 → 소프트웨어 정보 → "빌드번호" 7번 연속 탭
  → "개발자 모드가 켜졌습니다"
설정 → 개발자 옵션 → "탭할 때 시각적 효과 표시" 켜기
```

**촬영 끝나면 꺼두십시오.** 평소에 쓰면 눈에 거슬립니다.

## 1-C. 공통 — 촬영 전 폰 상태

```
□ 방해금지 모드 켜기          ← 알림이 화면에 뜨면 그 구간 다시 찍어야 합니다
□ 배터리 80% 이상
□ 화면 밝기 최대
□ 화면 자동 꺼짐 → 5분 이상
□ ★ 다크/라이트 모드 고정
```

**마지막 줄을 놓치기 쉽습니다.** 앱이 폰 테마를 따라가는데, 자동 전환이 켜져 있으면 촬영 중간에 화면색이 바뀝니다. **설정에서 라이트 또는 다크로 고정**하십시오. 밝은 쪽이 영상에서 잘 보입니다.

# STEP 2 · 첫 사용자 화면 만들기 ★이번 단계의 본론

## 2-A. 무엇이 "처음 쓰는 사람"을 결정하나

앱 코드를 확인했습니다. 온보딩 위저드는 **브라우저에 이 두 개가 없을 때** 뜹니다.

```
onehub_profile     투자성향 프로필
onehub_onboarded   온보딩 완료 표시
```

**중요한 사실: 이 둘은 서버에 동기화되지 않습니다.** (보유 종목·부동산 같은 건 동기화됩니다)

그래서 **브라우저 데이터만 지우면 온보딩이 다시 뜹니다.** 계정을 새로 만들 필요가 없습니다.

## 2-B. 세 가지 방법 — 하나만 고르십시오

### 방법 A · 평소 안 쓰는 브라우저로 촬영 ★가장 권합니다

평소 크롬을 쓰시면 사파리로, 사파리를 쓰시면 크롬으로 찍으십시오.

```
그 브라우저는 one-hub.kr 을 한 번도 안 열었으므로
  ✓ 주소 자동완성 없음      (처음 치는 장면이 자연스러움)
  ✓ 로그인 안 되어 있음      (카카오 로그인 장면을 찍을 수 있음)
  ✓ 온보딩이 뜸             (onehub_profile 이 없으므로)
  ✓ 홈 화면 아이콘 없음      (추가하는 장면을 찍을 수 있음)
  ✓ ★ 평소 쓰는 브라우저의 데이터를 하나도 안 건드림
```

**아이폰이면 주의**: "홈 화면에 추가"는 **사파리에서 가장 확실**합니다. 평소 사파리를 쓰신다면 방법 A 대신 방법 B로 가십시오.

### 방법 B · 같은 브라우저에서 one-hub.kr 데이터만 지우기

**아이폰 (사파리)**
```
설정 → Safari → 고급 → 웹사이트 데이터
→ 검색창에 "one-hub"
→ 나온 항목을 왼쪽으로 밀기 → 삭제
```

**안드로이드 (크롬)**
```
크롬으로 one-hub.kr 접속
→ 주소창 왼쪽 자물쇠(또는 ⓘ) 탭
→ 사이트 설정 → "데이터 삭제" → 확인
```

**★ 이 방법은 one-hub.kr 하나만 지웁니다.** 다른 사이트 로그인은 그대로입니다.

**지워지는 것과 돌아오는 것**

| | |
|---|---|
| 지워짐 | 로그인 · 온보딩 기록 · 화면 설정 |
| **로그인하면 서버에서 돌아옴** | 보유 종목 · ETF · 부동산 · 총자산 곡선 |
| **안 돌아옴** | 투자성향 프로필, 목표 배분 |

**투자성향은 온보딩을 다시 하면 됩니다** — 어차피 그 장면을 찍는 중이니까요. 다만 **촬영 후 원래 성향으로 다시 설정**하십시오.

### 방법 C · 온보딩 장면만 따로 찍기

온보딩은 **주소로 직접 들어갈 수 있습니다.**

```
one-hub.kr/pwa/onboarding
```

로그인된 상태에서 이 주소로 들어가면 온보딩 위저드가 그대로 뜹니다. **데이터를 아무것도 안 지우고** 그 장면만 찍을 수 있습니다.

**단, 끝까지 진행하지 마십시오.** 마지막 단계가 실제로 투자성향과 목표 배분을 덮어쓰고 첫 판단을 기록합니다. **마지막 화면 직전까지만 찍고 빠져나오십시오.**

### 어느 것을 고를까

```
안드로이드 사용     → 방법 A (크롬 말고 삼성인터넷, 또는 반대로)
아이폰 + 평소 크롬  → 방법 A (사파리로 촬영)
아이폰 + 평소 사파리 → 방법 B
번거로운 게 싫다     → 방법 C (온보딩만 따로, 나머지는 지금 상태로)
```

## 2-C. 그 밖에 정리할 것

```
□ 홈 화면에서 ONE·HUB 아이콘 삭제      ← 추가하는 장면이 U1의 핵심입니다
□ 읽지 않은 알림 미리 읽어 배지 없애기
□ 더미 종목 1개 입력 + 손절선을 현재가 근처로
     → "손절 임박"으로 맨 위에 올라와서, 그 카드만 화면에 담을 수 있습니다
```

본 촬영 전에 **짧게 한 번 찍어보고 확인**하십시오. 이걸 건너뛰면 4분을 다 찍고 나서 소리가 들어간 걸 발견합니다.

```

2) 앱을 아무렇게나 10초 조작

     □ 알림이 안 떴는가
     □ 터치 지점이 보이는가 (안드로이드)
     □ 화면색이 일정한가
     □ 글자가 화면 밖으로 안 나가는가
```

마지막 줄도 봐주십시오. 어제 고친 넘침이 폰에서도 잡혔는지 확인하는 자리입니다.

# STEP 4 · 세로 화면을 유튜브에 어떻게 올리나 ★미리 정해야 합니다

폰 화면은 **세로(9:16)**, 유튜브는 **가로(16:9)**입니다. 이걸 촬영 후에 고민하면 편집이 꼬입니다.

## 권하는 방식 — 가운데 세로, 좌우에 설명

```
┌──────────────────────────────────┐
│            │            │        │
│   설명     │  폰 화면   │  설명  │
│   자막     │  (세로)    │  자막  │
│            │            │        │
└──────────────────────────────────┘
        16:9 캔버스
```

**좌우 여백이 낭비가 아니라 자막 자리가 됩니다.** 버튼 이름, 강조 문구를 거기 넣으면 화면을 가리지 않습니다.

**좌우 배경**: 단색(앱의 짙은 녹색 계열)이 가장 깔끔합니다. 폰 화면을 흐리게 늘려 채우는 방식은 산만합니다.

## 다른 선택지

| 방식 | 언제 |
|---|---|
| **세로 그대로 9:16** | 쇼츠로만 낼 때. 일반 영상으로는 비권장 |
| **확대해서 16:9로 자르기** | 화면 위아래가 잘립니다. 하단 탭이 안 보여서 사용법엔 부적합 |

**U1은 가운데 세로 방식으로 가십시오.**

**여기까지 되면 알려주십시오.** 바로 녹화 순서로 넘어가겠습니다 — 네 덩어리로 나눠 찍는 법을, 그때는 구간별로 하나씩 짚어드리겠습니다.

막히는 데가 있으면 **어느 줄에서 막혔는지** 말씀해 주십시오. 폰 기종을 알려주시면 그 기종 화면 기준으로 다시 적어드릴 수 있습니다.
