```

```

이 둘은 서로 잘 맞습니다. 얼굴이 없으면 이름이 인격을 대신하고, 가명이면 목소리만 남기는 게 자연스럽습니다. 어중간한 조합(얼굴 없이 실명 / 얼굴 내고 가명)보다 일관됩니다.

## 1. 이름 — 「한곳」 그대로 쓰지 마시고 「한곳지기」를 권합니다

「한곳」은 좋은 착상입니다. **앱의 약속이 그대로 이름이 됩니다** — 흩어진 자산을 한곳에서. 다만 사람 이름으로 쓸 때 문제가 둘 있습니다.

### 문제 ① 검색이 안 됩니다

「한곳」은 일반명사입니다. "한곳에 모으다", "한곳으로 옮기다" — 검색하면 채널이 아니라 국어사전과 수천 개의 일상 문장이 나옵니다. **가명의 절반은 검색으로 찾아지기 위한 것**인데 그 기능을 잃습니다.

「한곳지기」는 검색하면 이 채널만 나옵니다.

### 문제 ② 사람인지 물건인지 구분이 안 됩니다

> "한곳이 이번 주에 틀린 것을 말씀드립니다"

앱이 말하는 건지 사람이 말하는 건지 모호합니다. 시청자가 댓글에서 부를 호칭도 마땅치 않습니다.

「한곳지기」는 **"한곳지기님"** 이 자연스럽습니다. 부를 수 있는 이름이어야 댓글이 달립니다.

### 왜 하필 「지기」인가

`지기`는 지키는 사람입니다 — 등대지기, 집지기, 문지기. **만드는 사람이면서 지키는 사람**이라는 뜻이 됩니다.

그리고 태도가 맞습니다. 이 채널의 주간 리포트는 매주 *"이번 주에 무엇을 틀렸는지"* 를 말하는 자리입니다. 「대표」나 「개발자」보다 「지기」가 그 낮은 자세에 어울립니다.

### 이름의 층위

세 이름이 충돌하지 않게 층을 나눕니다.

| 층 | 이름 | 쓰는 곳 |
|---|---|---|
| 채널 | **머니더버니** | 유튜브 채널명 · 기존 브랜드 |
| 앱 | **ONE·HUB** | 공식 제품명 · 도메인 · 앱 안 |
| 화자 | **한곳지기** | 영상 안 자기소개 · 댓글 · 자막 |

「한곳」은 **앱을 부르는 애칭**으로만 쓰십시오. 공식 제품명을 둘로 만들지 마십시오.

> "흩어진 걸 한곳에 모으자고 만든 앱이라, 저는 한곳지기라고 부릅니다."

한 번만 이렇게 말하면 세 이름이 전부 설명됩니다.

### 첫 영상에서 할 자기소개 (한 문장)

> "안녕하세요, 한곳지기입니다. 주식·부동산·연금이 흩어져 있는 게 답답해서 앱을 하나 만들고 있습니다."

**직업·나이·지역을 넣지 마십시오.** 자기소개가 길어질수록 신원이 좁혀집니다.

## 2. 목소리만 낼 때 — 실무

얼굴이 없으면 **음질이 곧 신뢰도**입니다. 영상의 인격이 목소리 하나에 걸려 있습니다.

### 장비 — 딱 하나만

폰 내장 마이크로는 4분을 못 버팁니다. 울림과 잡음이 그대로 들어가고, 시청자는 이유를 모른 채 나갑니다.

| 선택 | 비용 | 평 |
|---|---|---|
| 유선 이어폰 마이크 | 있는 것 | **시작은 이걸로 충분합니다.** 입에서 20cm |
| USB 콘덴서 마이크 | 5~10만원 | 3편쯤 찍고 계속할 것 같으면 그때 |
| 무선 핀마이크 | 5만원~ | 폰 촬영과 궁합 좋음 |

**처음부터 좋은 마이크를 사지 마십시오.** 3편을 못 찍고 그만두는 경우가 대부분입니다. 이어폰으로 3편을 찍은 뒤에 사십시오.

### 녹음 — 화면과 목소리를 따로

화면을 녹화하면서 동시에 말하면 **조작에 신경 쓰느라 말이 딱딱해집니다.** 순서를 나누십시오.

```
1) 화면만 녹화 — 소리 없이, 조작에만 집중
2) 녹화본을 보면서 목소리만 따로 녹음
3) 편집에서 합치기
```

목소리를 다시 녹음할 수 있다는 것만으로 톤이 달라집니다.

### 말투 — 얼굴이 없으니 이게 전부입니다

- **존댓말, 1인칭.** "저는 ~했습니다"
- **대본을 읽지 마십시오.** 읽으면 티가 납니다. 요점만 보고 말하십시오
- **예외: 후킹 20초는 외우십시오.** 첫 20초에서 시청자가 남을지 정합니다
- **말하다 막히면 다시 하십시오.** 편집으로 살리려 하지 마십시오
- **"쉽습니다" 금지.** 쉬운지는 보는 사람이 정합니다. 대신 **몇 분 걸리는지**를 말하십시오

### 조용한 시간

밤이 좋습니다. 에어컨·냉장고·환풍기를 끄고, **아파트 안내방송**을 조심하십시오 — 단지명이 나옵니다.

### 화면에 무엇을 채우나

얼굴이 없으니 화면은 계속 무언가를 보여줘야 합니다.

| 시리즈 | 화면 | 난이도 |
|---|---|---|
| **사용법** | 손가락 조작이 주인공 | **쉬움** — 목소리만과 궁합이 가장 좋습니다 |
| **주간 리포트** | `/pwa/weekly-report?record=1` 다섯 블록 | **쉬움** — 이미 만들어 뒀습니다 |
| **스토리** | 보여줄 화면이 적음 | **어려움** — 자막·정지 그래픽이 필요합니다 |

**그래서 순서가 또 한 번 확인됩니다.** 사용법 → 주간 리포트 → 스토리. 스토리를 먼저 찍으면 화면을 못 채워서 멈춥니다.

## 3. 가명 운영 규칙 — 무엇으로부터 숨는가

여기를 분명히 해야 합니다. **가명의 목적은 지인에게 숨는 것이 아닙니다.**

지인 30명은 어차피 압니다. 초대 메시지를 직접 보내니까요. 목소리도 알아봅니다.

가명이 지키는 것은 **회사와 불특정 다수로부터의 분리**입니다. 검색으로 실명이 나오지 않고, 회사 사람이 우연히 보더라도 곧바로 특정되지 않는 것.

### 그래서 지켜야 할 것

```
□ 실명 · 회사명 · 부서 · 직무 언급 금지
□ 채널 계정을 회사 메일로 만들지 말 것
□ 링크드인 · 회사 SNS와 연결 금지
□ 지인 초대 시 채널 홍보를 앞세우지 말 것
    → "제가 만든 앱이에요" 가 먼저, 채널은 그다음
□ 배경 소음에서 위치가 새지 않게 (아파트 안내방송)
□ 회사 사규 확인 — 겸업 · SNS 활동 · 수익 창출
```

마지막 줄을 **첫 촬영 전에** 확인하십시오. 채널이 커진 뒤에 문제가 되면 되돌릴 수 없습니다.

### 「서현동 이야기」는 거주지를 공개합니다

시리즈 이름 자체가 동네입니다. 이건 이미 내린 선택이고, 동네 단위는 수십만 명이라 그 자체로 특정되지는 않습니다.

**다만 겹치면 좁혀집니다.** 대본 0장에 적힌 조합 — 서현동 + 마흔여덟 + 대기업 18년 차 + 부장 — 이 한 화면에 모이면 같은 회사 사람은 하루면 압니다.

목소리만 내기로 하셨으니 얼굴 정보는 빠졌습니다. 나머지에서 **최소 하나는 흐리십시오.**

- 지역 → "서현동" 유지 (시리즈명이므로) 대신 **아래 둘을 흐림**
- 직장 → "대기업 18년 차" → **"직장 20년 가까이"**
- 나이 → "마흔여덟" → **"사십 대 후반"**

### 화자와 등장인물의 관계 — 3인칭 유지

대본 0장이 권한 **A안(3인칭)** 을 그대로 갑니다. 가명을 쓰기로 한 이상 더욱 그렇습니다.

> "분당에 사는 조 부장이라는 사람이 있습니다."

「한곳지기」가 「조 부장」의 이야기를 들려주는 구조입니다. 화자와 인물이 분리되어 있어 각색이 자유롭고, **"제 얘깁니다"로 시작했다가 되돌리는 건 불가능**합니다.

그리고 한 줄만 넣으면 진정성은 충분히 전달됩니다.

> "저도 그랬습니다."

## 5. 정하지 않은 것 하나

**목소리를 가공할지**는 정하지 않았습니다.

피치를 바꾸거나 변조하면 익명성은 올라가지만 **신뢰도가 크게 떨어집니다.** 자산 이야기에서 변조된 목소리는 치명적입니다.

권하지 않습니다. 변조가 필요할 만큼 걱정되신다면, 그건 목소리 문제가 아니라 **회사 사규를 먼저 확인해야 한다는 신호**입니다.
