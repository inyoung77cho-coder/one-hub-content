# 1. 화면을 어떻게 만드나 — 걱정하실 게 없습니다

이게 제일 고민이라고 하셨는데, **U1은 화면을 만들 게 없습니다.**

| 시리즈 | 화면을 만드나 | U1은? |
|---|---|---|
| **사용법** | **아니요** — 폰 화면 녹화가 전부 | ← 지금 이것 |
| 주간 리포트 | 아니요 — `?record=1` 화면 녹화 | |
| 스토리 | **네** — 자막 카드를 만들어야 함 | 나중 |

U1에서 화면에 나오는 건 **폰 화면 하나**입니다. 디자인도, 영상 소스도, 애니메이션도 필요 없습니다. 폰 화면을 녹화하고 거기에 목소리를 얹으면 끝입니다.

**만들어야 하는 건 딱 두 가지입니다.**

1. **썸네일 1장** — 제가 만들어 드렸습니다 (`U1_썸네일.jpg`)
2. **자막 카드 3장** — 제가 만들어 드렸습니다 (`카드_*.png`)

자막 카드는 화면이 전환될 때 잠깐 끼워 넣는 검은 배경 카드입니다. 없어도 영상은 됩니다. **처음엔 안 쓰셔도 됩니다.**

> 앞으로 카드가 더 필요하시면 문장만 알려주십시오. 같은 틀로 만들어 드리겠습니다.

# 2. 준비 (30분, 촬영 전날)

## 2-1. 계정 — 오늘은 시연 계정 없이 갑니다

### 실계정으로 그냥 찍으면 뭐가 새는가

U1에서 화면에 나오는 것 중 위험한 순서입니다.

| 새는 것 | 어디서 | 위험도 |
|---|---|---|
| **단지명** | 오늘 화면 아래 부동산 카드 | **최고 — 사는 곳이 특정됩니다** |
| **실명·이메일** | 카카오 로그인 화면 | **높음 — 가명이 무의미해집니다** |
| 보유 종목명 | 오늘 화면 종목 카드 | 중 |
| 총자산 금액 | 오늘 화면 상단 | 중 |
| 개인 알림 내용 | 알림 배지·토스트 | 낮음 |

### 그런데 U1은 대부분 안전합니다

구간별로 보면 이렇습니다.

```
0:00–0:50  주소 입력 · 브라우저      → 데이터 없음. 실계정 OK
0:50–1:10  카카오 로그인             → 실명 노출. ★ 편집에서 통째로 블러 (대본에 이미 있음)
1:10–2:00  홈 화면에 추가            → 데이터 없음. 실계정 OK
2:00–3:00  온보딩 5단계              → 데이터 없음. 실계정 OK
3:00–3:30  ★ 오늘 화면 + 판단 버튼    → ★ 여기만 문제
```

**4분 중 30초만 해결하면 됩니다.**

### 그 30초를 해결하는 법 — 더미 종목 하나

시연 계정을 만들지 말고, **실계정에 안 가진 종목을 하나 넣었다가 촬영 후 지우십시오.**

```
□ ＋ 버튼 → 실제로 안 가진 종목 하나 (예: 저가 종목) → 수량 1주
□ 평단가는 아무 값이나
□ ★ 손절선을 현재가와 비슷하게 잡으십시오
     → "손절 임박"으로 판정돼 오늘 화면 맨 위에 올라옵니다
□ 촬영 후 삭제
```

손절선을 현재가 근처로 잡는 게 요령입니다. 그러면 그 카드가 **맨 위에 오니까 카드 하나만 화면에 잡고 찍을 수 있습니다.** 아래 실제 보유 종목과 부동산 카드는 프레임에 안 들어옵니다.

```
□ 촬영은 종목 카드 하나만 클로즈업 (화면을 위로 스크롤한 상태에서 시작)
□ 상단 총자산이 프레임에 들어오면 → 편집에서 모자이크 (면적이 작습니다)
□ 부동산 카드까지 스크롤하지 마십시오
```

### 시연 계정은 언제 만드나

**U3·U4·U5를 찍기 전**입니다. 그 세 편은 앱 전체를 돌아다녀서 부동산 화면과 자산 화면이 통째로 나옵니다. 더미 종목으로는 못 가립니다.

만드는 법은 두 가지뿐이고 둘 다 번거롭습니다.

| 방법 | 비고 |
|---|---|
| **새 카카오 계정** | 카카오는 전화번호 하나당 계정 하나입니다. **별도 번호가 필요**합니다 — 알뜰폰 유심, 듀얼심, 안 쓰는 번호 |
| **가족 계정 빌리기** | 동의 필수. 그 사람 실명이 로그인 화면에 나오므로 **블러는 여전히 필요**하고, 그 사람 데이터가 없어야 합니다 |

**지금 이걸 하느라 촬영을 미루지 마십시오.** 오늘은 더미 종목으로 찍고, U3 촬영 전까지 번호를 하나 구하시면 됩니다.

### 촬영 전 체크

```
□ ★ 홈 화면에서 ONE·HUB 아이콘 삭제         ← U1의 핵심 장면입니다
□ 브라우저에서 one-hub.kr 방문 기록 삭제     ← 주소 자동완성이 뜨면 안 됩니다
□ 더미 종목 1개 입력 + 손절선을 현재가 근처로
□ 알림 배지 확인 — 읽지 않은 알림이 있으면 미리 읽어서 없애기
```

**두 번째 줄을 빠뜨리기 쉽습니다.** 주소를 치자마자 자동완성이 뜨면 "이미 쓰던 사람"이라는 게 보이고, 처음 시작하는 장면이 안 됩니다.

## 2-2. 폰 설정

**안드로이드** — 상단 빠른 설정에서 화면 녹화. 소리 **없음**으로.

# 3. 화면 녹화 (15분)

**말하지 마십시오. 조작만 합니다.**

대본(`유튜브_사용법_U1-U2_대본.md`의 U1)의 `**화면**:` 표시만 따라가면 됩니다.

## 녹화 순서 — 한 번에 다 찍지 말고 네 덩어리로

**① 브라우저에서 열기** (약 40초)
```
녹화 시작 → 브라우저 열기 → 주소창에 one-hub.kr/pwa 를 한 글자씩
→ 엔터 → 로딩 → 로그인 화면이 뜨면 녹화 중지
```
**자동완성을 쓰지 마십시오.** 타이핑하는 게 보여야 합니다.

**② 카카오 로그인** (약 20초)
```
녹화 시작 → 카카오 버튼 → 로그인 → 앱 첫 화면 → 중지
```
로그인 화면은 나중에 편집에서 흐리게 처리합니다. 지금은 그냥 찍으십시오.

**③ ★ 홈 화면에 추가** (약 60초) — 가장 중요
```
[아이폰] 녹화 시작 → 사파리 하단 공유 버튼 → 목록 아래로 스크롤
        → "홈 화면에 추가" → 추가 → 홈 화면에 아이콘 생긴 것 보여주기
        → 아이콘 눌러 실행 → 주소창 없는 전체 화면 → 중지
[안드로이드] 크롬 우상단 ⋮ → "홈 화면에 추가" → 같은 순서
```
**아이폰과 안드로이드 둘 다 찍으십시오.** 둘 중 하나만 있으면 나머지 절반의 시청자가 못 따라 합니다. 안드로이드 폰이 없으시면 그 부분은 말로만 설명하고, 그렇다고 자막에 적으십시오.

**④ 온보딩 + 첫 판단** (약 90초)
```
녹화 시작 → 온보딩 5단계 빠르게 통과 → 오늘 화면
→ 종목 카드 하나 → 판단 버튼 하나 누르기 → 기록된 표시 → 중지
```

## 녹화가 끝나면

네 개 파일이 생깁니다. **PC로 옮기십시오.** 카톡 나에게 보내기가 가장 빠릅니다(화질 유지 옵션 켜고).

# 5. 편집 (60분) — CapCut

**CapCut**을 쓰십시오. 무료고, 한국어 자동 자막이 잘 됩니다. PC판이 편합니다.

## 5-1. 얹기

```
1) 새 프로젝트 → 16:9
2) 화면 녹화 4개를 순서대로 끌어다 놓기
3) 음성 8개를 아래 트랙에 순서대로
4) 화면과 음성 위치 맞추기
   → 조작 시작 직전에 설명이 나오게. 설명이 먼저, 조작이 뒤
```

## 5-2. 잘라내기 ← 여기서 영상이 좋아집니다

```
5) 화면 녹화의 로딩 대기 시간 자르기
6) 말 없는 구간 0.5초 이상 자르기
7) 조작 중 헤맨 부분 자르기
```

**초보 영상과 아닌 영상의 차이는 이 단계입니다.** 4분짜리가 처음엔 6분쯤 됩니다. 잘라서 4분으로 만드십시오.

## 5-3. 자막

```
8) 텍스트 → 자동 자막 → 한국어
9) ★ 오타 수정 — "한곳지기"를 "한 곳 지기"로 씁니다
10) 버튼 이름은 자동 자막과 별개로 큰 글씨 추가
    「홈 화면에 추가」 「판단 버튼」 「＋ 버튼」
```

자막 위치는 화면 **아래 1/5** 지점. 더 아래로 내리면 유튜브 UI에 가립니다.

## 5-4. 가리기

```
11) 카카오 로그인 화면 → 모자이크 효과
12) 금액이 보이는 구간 → 모자이크
13) ★ 0.5배속으로 전체 한 번 보기 — 놓친 숫자 확인
```

## 5-5. 마무리

```
14) 자막 카드 3장을 전환 지점에 1.5초씩 (선택)
15) 마지막 5초에 고지 문구
16) 내보내기 1080p 30fps
```

**BGM은 넣지 마십시오.** 첫 편에는 필요 없습니다. 목소리가 유일한 인격인데 음악이 이기면 안 됩니다.

# 7. 첫 편에서 기대하실 것

**조회수는 거의 안 나옵니다.** 정상입니다. 유튜브는 3~6개월 뒤에야 검색으로 사람을 데려옵니다.

첫 편의 목적은 **지인에게 보낼 링크를 만드는 것**입니다. 앱 링크만 보내면 로그인 화면에서 닫히고, 영상을 먼저 보내면 열어봅니다.

**그래서 첫 편의 성공 기준은 조회수가 아니라 이것입니다.**

```
보낸 사람 6명 중 → 영상 본 사람 4명 → 앱 연 사람 3명 → 첫 판단 2명
```

이 정도면 잘 된 겁니다. 그리고 **"어디서 멈추셨어요?"** 라고 물어서 답을 받으십시오. 그게 다음 편의 소재이자 다음 스프린트의 할 일입니다.

# 8. 막히면

| 막힌 지점 | 이렇게 |
|---|---|
| 목소리가 이상하게 들린다 | 정상입니다. 자기 목소리는 원래 어색합니다. 3편이면 익숙해집니다 |
| 대본대로 말이 안 나온다 | 대본을 바꾸십시오. 대본이 당신 말투에 맞춰야지 반대가 아닙니다 |
| 편집이 안 끝난다 | 자막 카드와 BGM을 빼십시오. 없어도 됩니다 |
| 4분이 6분이 된다 | 5-2 잘라내기를 다시. 로딩 대기와 침묵부터 |
| 다시 찍고 싶다 | **올리십시오.** 첫 편은 원래 마음에 안 듭니다. 3편째부터 나아집니다 |

**첫 편을 완벽하게 만들려고 하면 두 번째 편이 안 나옵니다.** 4분짜리에 편집 2시간을 넘기지 마십시오.
