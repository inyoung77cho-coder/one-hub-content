작업일 2026-08-31 · Claude Code 세션

## 한 것 (`pages/pwa/index.js`)

- **종목코드→한글명 맵 `codeNameMap`** 신설. 채우는 순서(문서 지침대로):
  1. **보유 종목명(`data.balance.positions` 의 `name`, KIS 한글)** 우선.
  2. 추천 신호(`today_buys`/`screening_candidates`/`valid_signals`) 중 **국내(6자리 코드)인데 영문명**인 것만 `/api/stocks-search?q={code}` 로 조회해 한글명 보강(코드 일치 + 한글 응답만 채택, `cachedJson` 으로 중복제거, 최대 25개).
  3. 못 찾으면 **원문 유지**(실제 해외 상장 종목은 영문 그대로).
- **적용 지점**
  - `krName(code, fallback)` 헬퍼. 대시보드 TOP PICK `_mkPick.name` 에 적용.
  - 추천 탭 후보 원천 `uniqCands` 를 만들 때 `name` 을 한 번에 한글 정규화 → 하위 렌더(`s.name`)·핸들러(`logTake`/`logDecision`/`runAnalyze`/상세시트)가 모두 한글.
  - **판단 기록도 한글로**: `logDecision`·`actOnPending` 의 `recordDecision({name})` 이 `codeNameMap` 매핑을 우선 사용(영문 기록 방지). 두 useCallback 의 의존성에 `codeNameMap` 추가.
