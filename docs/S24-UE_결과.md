## S24-11 · 부동산 주간 현황 주차별 발행
- **기존 발행 재사용(새 수집기 없음)** — :5002 주간 부동산 리포트(`/api/re/weekly`, `weekly_report.py` 크론 `45 23 * * 0`, 메모리 FB-5)를 프론트에서 surface. ★지시서의 "weekly md 에 realestate 블록 추가" 대신 **기존 API 재사용**을 택함 — 한 주 리포트가 둘로 갈리지 않게 같은 주간 리포트 페이지에 통합(지시서 취지와 동일, 더 간단·정직).
- **`pages/pwa/weekly.js` 부동산 섹션(신규)** — 상단에 `🏠 부동산 주간 현황 · YYYY년 N주차 (M/D~M/D)`. `/api/pwa/re/weekly` 클라이언트 fetch로 지역 대장·실거래 건수·요약. **거래 없으면 "지난주 실거래 없음"**(부동산의 정상 상태), 리포트 없으면 정직한 안내. "분기·연 단위로 움직입니다 — 주간은 관찰 기록" 문구.
- **오늘 화면 연결** — `todayCadence` 에 **월요일 부동산 훅** 추가: weekly 페이지가 적립한 `onehub_re_weekly`(대장·실거래 건수)를 읽어 `지난주 부동산 · 내 지역 실거래 N건 · 대장 …`. **데이터 없으면 훅 미반환**.

**어디서 언제 보나:** 주간 리포트(`/pwa/weekly`) 최상단에 부동산 주간 카드(주차·기간·없음 표기). 월요일 오늘 화면 주기 카드에 지난주 부동산(weekly를 한 번이라도 연 사용자).

## S24-12 · 활동 토큰과 외국어 테스트
- **`lib/activityToken.js`(신규)** — `onehub_tokens_A/_B`(SYNC_KEYS 등록, S22-3·S23 방식). **gameWallet 과 분리**. `earn(kind)` 하루/주 상한: 판단 2(하루 6)·청취 3(하루 9)·브리핑 1(하루 1)·주간 열람 5(주 1). `spend`. `현금 교환 불가` 명시(`TOKEN_DISCLAIMER`).
- **획득 배선** — 판단(`recordDecisionWithPrice`)·외국어 1편 **끝까지 청취**(`AudioPlaylist` `ended`=100%, `onComplete`)·브리핑 청취(`BriefingSpeak` `ended`)·주간 열람(`weekly.js` 마운트). "끝까지"는 `ended`(100%)로 코드에 못박음 — 열자마자 닫으면 미적립.
- **외국어 테스트** — `pages/pwa/english-test.js`(신규). **그날 들은 학습(오늘 표현·단어)에서 규칙 기반 출제**(뜻→표현 4지선다, 최대 5문). 응시 10토큰. 결과는 `onehub_lang_tests_<trader>` 에 쌓이고 성적표에 외국어 항목으로 표시. **1차 규칙 기반**(LLM 미사용) — 문항은 오늘 학습의 표현·단어 수에 의존(부족하면 출제 불가로 정직히 안내).
- **표시 위치** — 현장경제(`english.js`) 토큰 pill + 테스트 링크, 성적표(`record.js`) 토큰·외국어 항목. **오늘·종합자산에는 미노출**.
- **위조 가능성 명시** — 클라이언트 저장이라 조작 가능. 자기 기록용은 무방하나 실제 보상(할인·현금성) 연결 시 **서버 검증 필요**(전자금융거래법). 코드 주석·이 문서에 기록.
- **streak 없음** — 연속 일수 배지 미사용.

**어디서 언제 보나:** 현장경제 상단 `🪙 N토큰 · 현금 교환 불가` + `오늘 들은 내용 테스트 →`. 성적표 하단 외국어·토큰 카드. 오늘/종합자산 화면엔 없음.
