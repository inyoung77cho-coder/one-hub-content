## 0. 시즌1과 무엇이 다른가

시즌1의 조 부장은 **이미 모은 사람**입니다. 물린 종목, 갈아타기, 세금, 인출. 자산이 있어서 생기는 고민입니다.

시즌2의 이 대리는 **모으는 중인 사람**입니다. 30대 초중반, 직장 5~8년 차. 자산이 적어서 생기는 고민이고, 완전히 다른 이야기입니다.

| | 시즌1 조 부장 | 시즌2 이 대리 |
|---|---|---|
| 단계 | 지키고 옮기는 단계 | 모으는 단계 |
| 금액 | 억 단위 | 천만 원 단위 |
| 불안 | "잘못 팔면 어떡하지" | "이대로 괜찮은 걸까" |
| 검색어 | 손절 · 양도세 · 갈아타기 | 연금저축 · 청약 · 적립식 |

**이 차이가 중요합니다.** 시즌1만 올리면 40대 이상만 옵니다. 시즌2가 30대를 데려옵니다. 그리고 30대가 이 앱을 더 오래 씁니다 — 모으는 기간이 길어서요.

### 인물 설정 (노출 범위 규칙 적용됨)

```
호칭   이 대리
나이   삼십 대 초중반          ← 구체적 나이 금지
직장   직장 생활 몇 년 차       ← 회사·업종 금지
지역   같은 동네                ← "서현동"은 시리즈명으로만
```

### 발행 순서 — 1화부터 올리지 마십시오

검색량이 가장 큰 편이 먼저입니다.

```
1) 4화  연금저축을 5년 만에 열어봤습니다    ← 검색량 최대
2) 1화  3년을 벌었는데 남은 게 없었습니다
3) 2화  청약통장을 3년 넣고 해지했습니다    ← 반응 갈림, 댓글 많음
4) 3화  적립식이면 안전한 줄 알았습니다
```
