# S24 UC 결과 — 조용한 날에도 할 말이 있게 (S24-7·8)

작업일 2026-09-03 · Claude Code

## S24-7 · 조용한 날의 오늘 (효용의 본체)
판단 카드가 **항상 렌더**되고(기존), 조치 0건일 때 우선순위 폭포로 채운다.
1. **조치 있으면** — 손절 임박·목표 도달 + [매도][보유][관망](S23 TC, 유지).
2. **조치 없으면 — 내 판단의 경과(신규)** — 최근 판단 3건의 **이후 수익률**(원장 `entry` 대비 현재가, positions 시세). 3거래일 지난 것은 정답/오답(✓/✗), 아직이면 `진행 중`. `entry_backfilled` 항목은 **(진입가 추정)** 표시(S19-2). "내 판단, 그 뒤로" 헤더.
3. **판단 기록 없으면 — 오늘의 관찰(신규)** — 손절선 최근접 3종목 + 각 `[관망]` 버튼. 누르면 `recordDecisionWithPrice(source:"today", pass)` → **조용한 날에도 판단 1건이 기록되어 사슬이 이어짐**. 새 저장소 없음.
4. **보유 없으면** — 연동 안내 한 줄.
- **관망 강요 안 함** — "기록하지 않아도 됩니다." 문구, 하루 1회(`getTodayDecision`).

**어디서 언제 보나:** 오늘 탭 자산 화면 판단 카드. 조치가 없는 대부분의 날엔 "내 판단, 그 뒤로 · 3일 전 보유 판단 삼성전자 +2.1% ✓" 처럼 매일 바뀌는 경과가, 신규 사용자는 손절선 최근접 3종목의 관망 버튼이 보인다.

## S24-8 · 성적표 상시 진입로
1. **판단 카드 하단 상시 노출** — 기록 유무와 무관하게 한 줄:
   - 기록 있음: `내 판단 N건 · 승률 X% · 성적표 →`
   - 30건 미만: `내 판단 N건 · M건 더 쌓이면 승률을 판정합니다 · 성적표 →`
   - 0건: `아직 판단 기록이 없습니다 · 성적표가 어떤 화면인지 보기 →`
   (getVerdictScorecard·samplePolicy 기반, 오늘 기록한 세션은 `오늘 N건 기록 · 성적표 →`)
2. **0건 성적표 화면** — `/pwa/record` 가 기록 0건일 때 빈 화면 대신 **예시 미리보기**(나 vs AI·승률·관망·놓친수익) + `예시 · 실제 데이터가 아닙니다` 배지 + 점선 카드로 실제와 구분. "판단을 남기면 내 실제 숫자로 채워집니다."
3. 하단 탭 재검토 없음.

**어디서 언제 보나:** 오늘 탭 판단 카드 맨 아래 항상. 기록 0건 사용자가 성적표를 눌러도 빈 화면이 아니라 예시(명확히 예시 표시)를 본다.
