## 2. 오늘의 핵심 — K5(임시공휴일) 실증

지시서 W5-3이 *"KIS 국내휴장일조회를 채택하라"*고 한 이유가 **오늘 실증됐습니다.**

```
2026-07-17   KIS = 휴장        ← 사용자 진술과 일치
             XKRX = 개장  ★불일치
2026-05-01   KIS = 휴장 / XKRX = 휴장   (근로자의날 K1 — 양쪽 일치)
2026-12-31   KIS = 휴장 / XKRX = 휴장   (연말 K2 — 양쪽 일치)
```

**`exchange_calendars`는 임시공휴일을 모릅니다.** 정부가 갑자기 지정하기 때문입니다.
KIS는 증권사 자신의 캘린더라 전부 들어 있습니다.

→ `market_calendar`의 KRX 판정을 **KIS 1차 · XKRX 폴백**으로 교체했습니다.
→ `market_status.py KRX` 결과: `after_close`(거짓) → **`closed_holiday`(참)**

### 이것이 없었다면 E-5도 무의미했습니다

오늘 **휴장인데 분석이 돌아** `screening_candidates` 30건 · `blocked_signals` 36건을 만들었습니다.
금요일이라 `_weekday_only`의 주말 검사를 통과했고, `main.py`에 `is_open` 게이트는 **0건**이었습니다.

게이트를 넣어도 **캘린더가 개장이라 하면 못 막습니다.** 그래서 순서가 `E-2 → E-5`였습니다.
