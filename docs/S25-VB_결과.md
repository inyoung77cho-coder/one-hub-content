## S25-4 · 자산 페이지 스와이프 (함정 처리)
- **함정 확인** — 자산 페이지의 상단 "탭"(0=주식/1=ETF/2=부동산)은 **선택 즉시 해당 페이지로 이동**하는 트리거라, 여기에 페이지 스와이프를 붙이면 밀 때마다 페이지가 튄다("페이지끼리는 클릭만" 위반).
- **스와이프 대상을 바꿈** — `pages/pwa/assets.js` 상단에 **자산군 요약 카드**(주식·ETF·부동산) 신설. 좌우 스와이프로 **이 카드만** 전환(`useSwipeTabs`, `sumIdx`). 카드: 평가액(`breakdown`) · 전일 대비(`getDelta` per class) · 목표 배분 이탈(`computeClassDrift`, S22-4) · 30일 스파크라인(자산군별 `hist` 시계열, `Sparkline` 재사용). 점 인디케이터.
- **페이지 이동은 클릭만** — 각 카드의 `상세 보기 →` 버튼만 `router.push`(주식=?tab=portfolio·ETF=/pwa/etf·부동산=/pwa/realestate).
- **스와이프 범위 제한** — 터치 핸들러를 `.as-sumcard` 에만 부착(페이지 전체 아님). 목록 영역에서 밀면 아무 일 없음.

**어디서 언제 보나:** 종합자산 상단 요약 카드에서 좌우로 밀면 주식↔ETF↔부동산 요약이 바뀌고, `상세 보기`를 눌러야 해당 페이지로 간다. 스와이프만으로는 절대 페이지 이동 안 됨.

## S25-5 · 나머지 페이지 스와이프
- **`useSwipeTabs` 재사용**(새로 안 만듦)으로 in-page 2탭 세그먼트에 붙임:
  - **ETF**(`etf.js`) 보유↔추천(`etfTab`) — `.etf` 루트에.
  - **부동산**(`realestate.js`) 분석↔시나리오(`reTab`) — `.re` 루트에.
- **주식 보유/추천** — 자산 페이지의 스와이프는 **S25-4의 요약 카드 캐러셀**이 담당(같은 페이지에 두 스와이프 zone 을 겹치면 이벤트 버블 충돌). 요약 카드가 자산 페이지의 스와이프 수단이며, 보유/추천 세그먼트는 클릭 유지. AI(VA)·듣는 경제(VC)는 각 묶음에서 처리.
- **하단 탭 사이 이동은 스와이프 미적용**(원칙 준수). 가로 스크롤 컨테이너 내 시작은 `useSwipeTabs` 함정2로 자동 제외.

**어디서 언제 보나:** ETF 페이지 좌우로 밀면 보유↔추천, 부동산 페이지 좌우로 밀면 분석↔시나리오. 표·칩 가로 스크롤은 탭을 안 넘김.
