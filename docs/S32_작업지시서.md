# S32 작업지시서 — 주간 리포트 제작 자동화

> 작성 2026-09-06 · 선행: S29(이야기 방송국), S30(깔때기·계기판), S31(공개도구·인출)
> 목표: **격주/매주 유튜브 "혼자 만드는 자산 앱" 주간 리포트를 사람이 3가지 일만 하고 만들 수 있게 한다.**
> 사람이 하는 3가지: ① 블록 3(배운 것·틀린 것) 고르기 10분 ② 촬영 40분 ③ 편집·발행 60분
> 나머지는 전부 이 스프린트에서 자동화한다.

---

## 0. 왜 이 작업인가

주간 리포트는 다섯 블록 고정 형식이다.

| 블록 | 내용 | 길이 | 현재 상태 |
|---|---|---|---|
| ① | 이번 주 숫자 | 40초 | 숫자가 **AI 탭 정비소**에 있음 |
| ② | 이번 주 만든 것 | 100초 | `docs/S**_결과.md`에 있음 (개발 용어) |
| ③ | **이번 주 배운 것·틀린 것** | 120초 | 심판석에 있으나 **사람이 골라야 함** |
| ④ | 시장에서 있었던 일 | 100초 | 심판석·정비소·주간 부동산에 흩어져 있음 |
| ⑤ | 다음 주에 할 것 | 40초 | 작업지시서에 있음 |

**문제는 두 가지다.**

1. **촬영하려면 화면을 대여섯 번 옮겨야 한다.** 정비소 → 심판석 → 부동산 → 다시 정비소. 40분 촬영이 90분이 된다.
2. **대본을 매주 손으로 쓴다.** 소재는 전부 앱 안에 있는데, 매주 같은 형식으로 다시 조립한다.

이 스프린트는 **①을 한 화면으로 모으고, ②를 자동 초안으로 만든다.**

**만들지 않는 것**: 자동 영상 편집, 자동 업로드, TTS 나레이션. 사람의 목소리와 판단이 이 시리즈의 유일한 차별점이다.

## 1. 전제 조건 (어기면 앱이 죽는다)

```
1) 빌드는 반드시  next build --webpack
   → package.json의 "build" 스크립트를 절대 바꾸지 말 것.
     Turbopack 프로덕션 빌드는 하이드레이션을 깨고 PWA가 먹통이 된다.

2) 저장소 전체가 CRLF다.
   → 리눅스에서 편집할 때 줄바꿈을 LF로 바꾸지 말 것. 유령 diff가 생긴다.

3) middleware.js의 PROTECTED_API_PREFIXES는 fail-closed 화이트리스트다.
   → 새 API를 만들고 여기 등록하지 않으면 그 API는 공개된다.

4) 배포는 git push origin main (Vercel 자동).
   → 엔진(Lightsail) 쪽은 이번 스프린트에서 건드리지 않는다.

5) 이 스프린트는 기존 화면의 레이아웃을 바꾸지 않는다.
   → 새 페이지 하나(/pwa/weekly-report)와 라이브러리만 추가한다.
```

## 배치 BA — 주차 데이터 집계

### S32-1 · `lib/weeklyDigest.js` 신설

**할 일**

주차 하나에 해당하는 다섯 블록 데이터를 한 번에 모으는 순수 함수 모듈을 만든다.

```js
// lib/weeklyDigest.js
export function weekBounds(dateISO)   // 월요일 00:00 ~ 일요일 23:59 (KST). 주차 번호 반환
export async function buildDigest(weekNo) // → { week, block1..block5 }
```

**각 블록의 데이터 출처 — 새로 조사하지 말 것. 전부 이미 있다.**

| 블록 | 출처 | 비고 |
|---|---|---|
| ① 숫자 | S30-9 가입 깔때기 API | 가입·온보딩완료·보유입력·첫판단·7일재방문 |
| ② 만든 것 | `docs/S*_결과.md` 파일들 | 주차 경계 안에 커밋된 것만 |
| ③ 배운 것·틀린 것 | 심판석 정확도 API + `by_reason` | **후보만 뽑고 고르지 않는다** (S32-6 참조) |
| ④ 시장 | 심판석 주간 요약 + `engine_changes` 원장(S28-1) + 주간 부동산(S24-11) | |
| ⑤ 다음 주 | `docs/S*_작업지시서.md` 중 미완료 최신 것의 첫 배치 | 항목 **하나만** |

**주의**

- 블록 ②는 결과 문서의 "한 것" 항목만 읽는다. 파일 전체를 넣지 말 것.
- 데이터가 없는 블록은 **빈 배열을 반환하고 오류를 던지지 않는다.** 만든 게 없는 주가 정상이다.
- `weekBounds`는 KST 기준. 서버가 UTC이므로 오프셋을 명시적으로 처리할 것.

**검증**: 지난 3개 주차에 대해 `buildDigest`를 돌려 다섯 블록이 모두 채워지거나 빈 배열인지 확인. 예외가 나면 실패.

### S32-2 · `/api/weekly/digest` — 관리자 전용

**할 일**

```
GET /api/weekly/digest?week=2026-W36
→ { ok: true, digest: {...} }
```

- `x-oh-role !== "admin"` 이면 **403**. 이 API는 운영 내부 숫자를 담는다.
- `middleware.js`의 `PROTECTED_API_PREFIXES`에 **`/api/weekly/` 를 추가**한다. (fail-closed 화이트리스트이므로 등록하지 않으면 공개된다)
- 캐시: `s-maxage=600` (주차 데이터는 자주 안 바뀐다)

**검증**
1. 관리자 세션으로 200 + 다섯 블록
2. **비관리자 세션으로 403** ← 이걸 확인하지 않고 넘어가지 말 것
3. 세션 없이 403

## 배치 BB — 녹화용 한 화면

### S32-3 · `/pwa/weekly-report` 페이지

**할 일**

다섯 블록을 **순서대로 하나씩** 보여주는 페이지를 만든다. 스크롤이 아니라 **블록 단위 전환**이다.

```
[① 이번 주 숫자]   ← 지금 보이는 블록
   좌우 스와이프 또는 ← → 키로 다음 블록
하단에  ● ○ ○ ○ ○   진행 표시
```

- 관리자 전용. 비관리자는 `/pwa/today`로 리다이렉트.
- 각 블록은 **한 화면에 다 들어와야 한다.** 넘치면 글자를 줄이지 말고 항목 수를 줄인다(상위 3개).
- 블록별 목표 길이를 화면 구석에 표시: `① 40초`, `③ 120초`. 촬영 중 페이스 조절용.

**주의**: 기존 `BottomNav`, 헤더, 스와이프 라우팅과 **충돌하지 않게** 할 것. 이 페이지는 탭 목록에 넣지 않는다. 접근은 AI 탭 정비소 안의 링크 하나로만.

### S32-4 · 녹화 모드 `?record=1`

**할 일**

`?record=1`이 붙으면 촬영에 방해되는 것을 전부 끈다.

| 끄는 것 | 이유 |
|---|---|
| 하단 탭 · 헤더 | 화면에 찍히면 안 됨 |
| 모든 애니메이션 · 카운트업 | 촬영 중 흔들림 |
| 알림 배지 · 토스트 | 갑자기 튀어나옴 |
| 시스템 다크모드 추종 | **다크 고정** — 촬영 조명 일관성 |

추가로:
- **16:9 세이프 영역 가이드**를 반투명 테두리로 표시(`?record=1&guide=1`일 때만). 촬영 후 편집에서 잘릴 부분을 미리 본다.
- 글자 크기를 기본의 **1.4배**로. 유튜브는 폰으로 보는 사람이 많다.

**주의**: S26에서 만든 폰트 크기 토큰을 쓸 것. 새 하드코딩 px를 넣지 말 것.

---

### S32-5 · 마스킹 스위치 (기본 ON)

**할 일**

영상에 나가면 안 되는 것을 자동으로 가린다. **기본값은 ON이다.** 끄는 것은 명시적 조작으로만.

| 가리는 것 | 표시 |
|---|---|
| 실제 자산 금액 | `██.█억` |
| 보유 종목명 | `A종목`, `B종목` |
| 사용자 실명 | `이용자 1` |
| 단지명 | `분당 A단지` |
| 계좌번호 일부 | 기존 마스킹 유지 |

**가리지 않는 것**: 가입자 수, 판단 건수, 정확도 %, 수익률 %. 이건 리포트의 본체다.

**주의**: 마스킹은 **렌더 시점**이 아니라 **데이터 반환 시점**에 걸 것. 화면에서만 가리면 DOM에 원본이 남아 실수로 노출된다. `?record=1`일 때 API가 마스킹된 값을 내려주는 방식.

## 배치 BC — 주간 소재 묶음 자동 생성

### S32-6 · `buildWeeklyScript(digest)` — 대본 초안

**할 일**

S29-8에서 만든 `lib/episodeDraft.js`를 확장한다. 새 파일을 만들지 말고 **같은 모듈에 함수를 추가**한다.

```js
export function buildWeeklyScript(digest, opts) // → { blocks: [...], totalSec, warnings: [] }
```

**분량 규칙 — 말하기 속도 분당 330자 기준**

| 블록 | 목표 | 글자수 상한 |
|---|---|---|
| ① 숫자 | 40초 | 220자 |
| ② 만든 것 | 100초 | 550자 |
| ③ 배운 것·틀린 것 | 120초 | 660자 |
| ④ 시장 | 100초 | 550자 |
| ⑤ 다음 주 | 40초 | 220자 |
| **합계** | **400초 (6분 40초)** | |

상한을 넘으면 잘라내지 말고 `warnings`에 담아 화면에 표시한다. 사람이 무엇을 뺄지 정한다.

**블록 ③은 자동으로 쓰지 않는다.**

이게 이 시리즈의 심장이고, 자동 생성하면 죽는다. 대신 **후보 3~5개를 뽑아 사람에게 고르게 한다.**

```
③ 후보
[ ] 손절 규칙 R7이 이번 주 4번 중 3번 틀렸습니다 (심판석)
[ ] 관망이 정답이었던 날이 2일 (avoided, S30-5)
[ ] ETF 시세가 한 번 잘못 나왔습니다 (.KQ 폴백)
[ ] (직접 입력)
```

고른 항목은 **뼈대만** 생성한다: "무엇이 있었는지 → 왜 그랬는지 → 그래서 뭘 바꿨는지". 살은 사람이 붙인다.

### S32-7 · 제목 3안 · 챕터 · 설명란

**할 일**

한 번의 호출로 발행에 필요한 부속물을 전부 만든다.

**제목** — 고정 형식을 지키되 뒷부분 한 줄만 3안:
```
혼자 만드는 자산 앱 · 12주차 | 손절 규칙이 세 번 틀렸습니다
혼자 만드는 자산 앱 · 12주차 | 가입자 31명, 그중 첫 판단은 14명
혼자 만드는 자산 앱 · 12주차 | 이번 주에 고친 것과 못 고친 것
```

3안은 서로 **다른 블록**에서 뽑을 것(③에서 하나, ①에서 하나, ②에서 하나). 같은 소재의 말바꾸기는 3안이 아니다.

**챕터** — 블록별 목표 길이 누적으로 타임코드 생성:
```
0:00 이번 주 숫자
0:40 이번 주 만든 것
2:20 이번 주 배운 것·틀린 것
4:20 시장에서 있었던 일
6:00 다음 주에 할 것
```

**설명란** — 고정 문구 + 이번 주 요약 3줄 + 앱 링크 + 사용법 가이드 링크. 고정 문구는 상수로 두어 매주 같게.

**썸네일 텍스트 제안**: 회차 번호 크게 + 한 줄. 제목 3안의 첫 번째에서 명사구만 뽑는다.

### S32-8 · 개발 용어 번역 사전

**할 일**

결과 문서의 문장을 그대로 옮기면 아무도 안 읽는다. 블록 ②에 **번역층**을 넣는다.

```js
// lib/episodeDraft.js 안에 상수로
const TERM_MAP = [
  [/allHoldings\s*통합/, "직접 입력한 종목도 오늘 화면에 나옵니다"],
  [/레이트리밋/,        "너무 많이 조회하면 잠시 쉬게 했습니다"],
  [/하이드레이션/,      "화면이 처음 뜰 때 멈추던 문제"],
  // ...
];
```

- 매칭되지 않은 기술 용어(영문 대문자 3자 이상, 스프린트 코드 `S\d+-\d+`, 파일 경로)는 **`⚠️ 번역 필요`** 로 표시해 화면에 띄운다. 조용히 통과시키지 말 것.
- 사전은 매주 자라야 한다. 새 항목 추가가 쉽도록 배열 하나에 모아둔다.

**판정 기준**: 블록 ② 초안에 스프린트 코드나 파일명이 하나라도 남아 있으면 실패다.

### S32-10 · 검증

**전부 통과해야 완료다.**

```
□ npm run build  (= next build --webpack) 성공
□ /pwa/weekly-report 관리자 200 / 비관리자 리다이렉트
□ /api/weekly/digest 비관리자 403  ← 반드시 직접 확인
□ ?record=1 에서 하단탭·헤더·애니메이션 전부 사라짐
□ 마스킹 ON 상태에서 API 응답 자체에 금액·종목명이 없음 (DOM 아님, 네트워크 탭에서 확인)
□ 소재가 없는 주차로 호출 → 오류 없이 "이번 주는 만든 게 없습니다" 노출
□ 블록 ② 초안에 스프린트 코드·파일명이 남아 있지 않음
□ 다섯 블록 목표 길이 합이 400초 ± 60초
□ git diff 에 CRLF 유령 변경 없음
```

**빈 주차 처리를 대충 넘기지 말 것.** 만든 게 없는 주가 반드시 온다. 그 주에 오류 화면이 뜨면 리포트가 끊긴다.

## 3. 이 스프린트가 끝나면 사람이 하는 일

```
토요일 아침
  1. /pwa/weekly-report 열기            (자동 생성된 다섯 블록)
  2. 블록 ③ 후보에서 하나 고르고 살 붙이기   ← 10분, 사람만 할 수 있는 일
  3. ?record=1 로 촬영                   ← 40분
  4. 대본 복사 → 편집 → 발행              ← 60분
```

**목표는 주 1편이다.** 주 2편은 두 달 안에 무너진다.
