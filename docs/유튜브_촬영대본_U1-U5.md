# 촬영 대본 U1~U5 — 조작 순서와 나레이션 통합

> 작성 2026-09-13 · 안드로이드 기준 · 화자 「한곳지기」 목소리만
> **이 문서 하나만 보고 찍고 녹음합니다.** 찍을 것과 말할 것이 구간마다 붙어 있습니다.
> 순서는 **실제 앱 동작 순서**로 맞췄습니다 — 대본 원본과 다릅니다(아래 참조).

---

## 0. 이 문서 읽는 법

각 구간이 이렇게 되어 있습니다.

```
### 덩어리 N · 제목   [시각]
**찍기**   — 손가락으로 할 일. 녹화 중 말하지 않습니다
**말하기** — 나중에 따로 녹음할 문장. 파일명이 붙어 있습니다
**자막**   — 편집에서 큰 글씨로 넣을 것
```

**촬영과 녹음은 따로입니다.** 먼저 덩어리별로 화면만 찍고, 다 모이면 그 영상을 보면서 구간별로 목소리를 녹음합니다.

### 공통 규칙

```
□ 덩어리마다 앞뒤 2초 정지 — 편집 여유분
□ 손가락은 평소의 70% 속도
□ 스크롤을 아래로 내리지 말 것 (실제 보유 종목·단지명 노출)
□ 나레이션은 대본을 읽지 말고 요점만 보고 말할 것
□ 예외: 후킹 20초는 외울 것
□ 모든 편 마지막 5초에 고지 문구 자막
```

### ★ U1 순서를 바꾼 이유

원본 대본은 `로그인 → 홈 화면 추가 → 온보딩` 순이었습니다. 그런데 앱은 **로그인하면 곧바로 온보딩으로 넘어갑니다**(코드 확인). 사용법 영상은 사용자가 겪는 순서 그대로여야 하므로 실제 흐름에 맞췄습니다.

# U1 · 3분 만에 시작하기
**4분** · 재생목록 사용법 · 1주차 발행

### 덩어리 ⓪ · 후킹 [0:00–0:20]

**찍기**
```
1. 폰 홈 화면에서 증권사 앱 열기 → 2초 → 뒤로
2. 부동산 앱 열기 → 2초 → 뒤로
3. 은행/연금 앱 열기 → 2초 → 뒤로
4. 화면 끄기
```
앱이 없으면 홈 화면에서 아이콘 세 개를 차례로 가리키는 것으로 대신하십시오.

**말하기** `u1_01_후킹` — ★ 이것만 외우십시오
> 주식은 증권사 앱, 부동산은 호갱노노, 연금은 또 다른 앱.
> 세 군데를 열어야 제 자산이 얼마인지 알 수 있었습니다.
> 【쉼】
> 그걸 한 화면으로 합치는 데 **3분** 걸립니다.
> 설치할 것도, 가입 양식도 없습니다.

3. 주식 → ETF → 부동산 단계를 차례로 넘기기

> 여기서 정확하게 답하려고 하지 마십시오.
> 이건 설문이 아니라, 첫 화면을 뭘로 채울지 정하는 것뿐입니다.
> 가진 게 없는 항목은 비워두고 넘기셔도 됩니다.

**자막**: `모르면 건너뛰세요`

### 덩어리 ④ · 홈 화면에 추가 [2:10–3:00] ★이 편의 핵심

**찍기**
```
1. (2초 정지) — 오늘 화면이 보이는 상태
2. 크롬 오른쪽 위 ⋮ 탭
3. "홈 화면에 추가" 또는 "앱 설치" 탭 → 확인
4. ★ 홈 버튼으로 홈 화면 나가기
5. ★ 생긴 아이콘을 1~2초 보여주고 탭
6. ★ 주소창 없는 전체 화면으로 열리는 것
7. (2초 정지) → 중지
```

**4~6번을 빠뜨리면 이 구간이 의미가 없습니다.** 추가만 하고 끝내면 "그래서 뭐가 좋은데?"가 됩니다.

**말하기** `u1_06_홈화면`
> 여기가 제일 중요합니다.
> **이걸 안 하면 다음에 또 주소를 쳐야 합니다.** 그리고 대부분 다시 안 옵니다.
> 【쉼】
> 크롬 오른쪽 위 점 세 개, "홈 화면에 추가".
> 아이폰은 사파리 아래 공유 버튼에 같은 메뉴가 있습니다.
> 【쉼】
> 이제 아이콘으로 열립니다. 주소창이 없어졌죠. 앱과 똑같습니다.

**자막**: `⭐ 홈 화면에 추가 — 이걸 해야 다시 옵니다`

1. 오늘 화면 맨 위 종목 카드
2. ★ 스크롤을 내리지 말 것
3. 판단 버튼 세 개가 보이게
4. "관망" 탭
5. 기록됐다는 표시까지
6. (2초 정지) → 중지
```

**말하기** `u1_07_판단`
> 마지막으로 하나. **이게 이 앱의 시작점입니다.**
> 오늘 이 종목을 어떻게 할지 한 번 누릅니다. 보유, 매도, 관망.
> 【쉼】
> 저는 관망을 누르겠습니다. **아무것도 안 하기로 한 것도 판단입니다.**
> 맞았는지 틀렸는지는 나중에 앱이 알려줍니다.
> 【쉼】
> 이 버튼을 한 번도 안 누르면 이 앱은 그냥 자산 계산기입니다.
> **눌러야 성적표가 생깁니다.**

**자막**: `⭐ 판단 버튼 — 여기서부터 시작입니다`

**자막**: `연동 안 해도 기능 차이 없습니다`

### 덩어리 ② · ETF 입력 [1:30–2:20]

**찍기**
```
1. ＋ → ETF
2. 티커 입력 (예: 069500)
3. 수량·평단가 → 저장
4. 중지
```

**말하기** `u2_04_etf`
> ETF도 같습니다. 다만 **티커**를 넣습니다.
> 국내 ETF는 여섯 자리 숫자, 해외는 알파벳입니다.
> 모르시면 증권사 앱에서 종목 화면 위에 적혀 있습니다.
> 【쉼】
> 여기서 하나 말씀드리면, ETF를 여러 개 가지고 계신 분들은
> **겹치는 게 없는지** 나중에 자산 화면에서 확인해 보십시오.
> 분산한 줄 알았는데 같은 종목을 세 번 산 경우가 생각보다 많습니다.

# U3 · 매일 3분 루틴
**5분** · 5주차 발행

### 덩어리 ⓪ · 후킹 [0:00–0:20]

**찍기**: 증권사 앱을 몇 초 간격으로 새로고침하는 손 → 화면 끄기

**말하기** `u3_01_후킹` — 외우십시오
> 계좌를 하루에 몇 번 보십니까.
> 저는 한때 스무 번씩 봤습니다. 그런다고 수익률이 오르지는 않더군요.
> 【쉼】
> 그래서 이 앱은 **오래 보라고 만들지 않았습니다.**
> 아침에 3분. 오늘은 그 3분에 뭘 하는지 보여드리겠습니다.

### 소개 [0:20–0:22] → `한곳지기입니다.`

---

### 덩어리 ① · 아침에 오늘 화면 [0:22–1:10]

**찍기**
```
1. 홈 화면 아이콘 탭 → 오늘 화면 로딩 (실시간)
2. 맨 위 종목 카드
3. 배지를 하나씩 천천히 확대
4. 중지
```

**말하기** `u3_02_오늘화면`
> 아침에 아이콘을 누르면 이 화면이 먼저 뜹니다. **오늘** 화면입니다.
> 맨 위에 오늘 조치가 필요한 종목만 올라옵니다.
> 가진 종목 전부가 아니라, **오늘 뭔가 봐야 하는 것만** 나옵니다.
> 【쉼】
> 배지가 세 가지입니다.
> 손절선에 가까워졌으면 **손절 임박**,
> 목표가에 왔으면 **익절 검토**,
> 하루에 크게 움직였으면 **점검 필요**.

**자막**: `손절 임박 · 익절 검토 · 점검 필요`

---

### 덩어리 ② · 판단 버튼 세 경우 [1:10–2:20]

**찍기**
```
1. 판단 버튼 3개 클로즈업
2. 손절 임박 종목에 "매도" 누르기
3. 점검 필요 종목에 "보유" 누르기
4. "관망" 누르기
