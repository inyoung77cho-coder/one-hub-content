# 안드로이드 촬영 준비 — 여섯 단계

> 작성 2026-09-13 · U1 촬영 직전 · **안드로이드 전용**
> 삼성 갤럭시 기준으로 적었습니다. 다른 기종이면 메뉴 이름이 조금 다를 수 있으나 순서는 같습니다.
> 폰만 들고 위에서부터 따라가시면 됩니다. **15분** 걸립니다.

---

# STEP 1 · 화면 녹화 설정 (5분)

## 1-1. 녹화 설정을 먼저 바꿉니다

**빠른 설정에서 바로 시작하지 마십시오.** 설정부터 잡아야 합니다.

```
설정 → 유용한 기능 → 화면 캡처 및 화면 녹화
   → 화면 녹화 설정
```

여기서 세 가지를 바꿉니다.

| 항목 | 설정할 값 | 왜 |
|---|---|---|
| **소리** | **소리 없음** | ★ 목소리는 나중에 따로 녹음합니다. 켜두면 주변 소음이 다 들어갑니다 |
| **동영상 화질** | **1080p** (최고) | 720p로 찍으면 유튜브에서 글자가 뭉갭니다 |
| **화면 터치 표시** | **켜기** | ★ 어디를 눌렀는지 보입니다. 사용법 영상의 핵심 |

메뉴에 "화면 터치 표시"가 없으면 STEP 2로 가십시오. 거기에 더 확실한 방법이 있습니다.

## 1-2. 빠른 설정에 녹화 버튼 꺼내기

```
화면 위에서 두 손가락으로 아래로 쓸어내리기 (빠른 설정 전체 열림)
→ 오른쪽 위 ⋮ 또는 ＋ → 버튼 편집
→ "화면 녹화"를 위쪽 영역으로 끌어다 놓기 → 완료
```

## 1-3. 시작·중지 익히기

```
시작: 빠른 설정 → 화면 녹화 → (설정창 뜨면) 녹화 시작 → 3초 카운트
중지: 화면 위 작은 컨트롤 바의 ■ 정지 버튼
      또는 상단 알림 내려서 중지
저장: 갤러리 → "화면 녹화" 앨범
```

**컨트롤 바는 녹화본에 안 찍힙니다.** 걱정 안 하셔도 됩니다.

# STEP 2 · 터치 지점 선명하게 (3분)

빠른 설정의 터치 표시가 흐리거나 없으면 **개발자 옵션** 쪽이 훨씬 잘 보입니다.

## 2-1. 개발자 옵션 켜기

```
설정 → 휴대전화 정보 → 소프트웨어 정보
→ "빌드번호"를 7번 연속 탭
→ "개발자 모드를 켰습니다" 메시지
```

## 2-2. 탭 표시 켜기

```
설정 → 개발자 옵션 (목록 맨 아래쯤)
→ "탭할 때 시각적 효과 표시" 켜기
```

화면을 아무 데나 눌러보십시오. **하얀 동그라미**가 뜨면 된 겁니다.

> **촬영이 끝나면 꺼두십시오.** 평소에 켜두면 눈에 거슬립니다.

# STEP 3 · 폰 상태 정리 (2분)

```
□ 방해금지 모드 켜기              ← 알림이 뜨면 그 구간 다시 찍습니다
□ 배터리 80% 이상 (충전 케이블 꽂고 찍으면 편합니다)
□ 화면 밝기 최대
□ 설정 → 디스플레이 → 화면 자동 꺼짐 → 5분 이상
□ ★ 설정 → 디스플레이 → 라이트 모드 고정
□ 상단 알림 아이콘 정리 — 읽지 않은 알림 미리 읽기
```

**다크 모드 자동 전환을 끄십시오.** 앱이 폰 테마를 따라가기 때문에, 자동 전환이 켜져 있으면 촬영 중간에 화면색이 바뀝니다. 영상에서는 **라이트 모드가 잘 보입니다.**

## 화면 비율 팁 (선택)

하단에 세 개 버튼(◁ ○ ‖)이 있으면 화면이 그만큼 좁아집니다. **제스처로 바꾸면 화면이 넓고 깔끔합니다.**

```
설정 → 디스플레이 → 내비게이션 바 → 스와이프 제스처
```

평소 손에 익은 방식이 편하시면 그냥 두셔도 됩니다. 영상 품질에 큰 차이는 아닙니다.

# STEP 4 · 첫 사용자 화면 만들기 (3분) ★핵심

## 어느 브라우저로 찍을지 정합니다

안드로이드에는 보통 **크롬**과 **삼성 인터넷**이 둘 다 있습니다. 이걸 이용합니다.

```
평소 삼성 인터넷을 쓴다  →  ★ 크롬으로 촬영   (STEP 4-A)
평소 크롬을 쓴다         →  ★ 삼성 인터넷으로 촬영 또는 크롬 데이터만 삭제 (4-B)
```

**추천은 크롬으로 찍는 것입니다.** 안드로이드에서 "홈 화면에 추가"가 가장 매끄럽고, 설치하면 주소창 없는 진짜 앱처럼 열립니다.

## 4-A · 평소 안 쓰던 브라우저로 (가장 깔끔)

그 브라우저는 one-hub.kr을 한 번도 안 열었으므로 **아무것도 지울 필요가 없습니다.**

```
✓ 주소 자동완성 없음 → 처음 치는 장면이 자연스러움
✓ 로그인 안 되어 있음 → 카카오 로그인 장면을 찍을 수 있음
✓ 온보딩이 뜸
✓ 홈 화면 아이콘 없음 → 추가하는 장면을 찍을 수 있음
✓ 평소 쓰는 브라우저를 하나도 안 건드림
```

**그냥 그 브라우저를 열고 촬영으로 넘어가시면 됩니다.**

## 4-B · 같은 브라우저에서 one-hub.kr 데이터만 지우기

**크롬**
```
크롬으로 one-hub.kr 접속
→ 주소창 왼쪽 자물쇠 또는 ⓘ 아이콘 탭
→ 사이트 설정 (또는 권한 및 데이터)
→ "데이터 삭제" → 확인
```

**삼성 인터넷**
```
삼성 인터넷 → ≡ → 설정 → 인터넷 사용 기록
→ "인터넷 사용 기록 삭제"에서 쿠키·사이트 데이터 선택
```
삼성 인터넷은 사이트별 삭제가 어려워 전체가 지워질 수 있습니다. **그래서 4-A를 권합니다.**

### 지워지는 것과 돌아오는 것

| | |
|---|---|
| 지워짐 | 로그인 · 온보딩 기록 · 화면 설정 |
| **로그인하면 서버에서 돌아옴** | 보유 종목 · ETF · 부동산 · 총자산 곡선 |
| 안 돌아옴 | 투자성향 프로필 · 목표 배분 |

투자성향은 온보딩을 다시 하면 됩니다 — 어차피 그 장면을 찍는 중입니다. **촬영 후 원래 성향으로 다시 설정**하십시오.

## 4-C · 온보딩만 따로 찍는 방법 (아무것도 안 지움)

온보딩은 주소로 직접 들어갑니다.

```
one-hub.kr/pwa/onboarding
```

**단, 마지막 단계까지 진행하지 마십시오.** 그 단계가 실제로 투자성향과 목표 배분을 덮어씁니다. 마지막 화면 직전까지만 찍고 뒤로 나오십시오.

## 4-D · 공통 — 반드시

```
□ 홈 화면에서 ONE·HUB 아이콘 길게 눌러 삭제
     ← 추가하는 장면이 U1의 핵심입니다. 이미 있으면 못 찍습니다
```

# STEP 5 · 더미 종목 넣기 (2분)

마지막 30초에 판단 버튼 장면을 찍는데, 실제 보유 종목이 화면에 나오면 안 됩니다.

```
□ 평소 쓰는 브라우저·앱에서 ONE·HUB 열기 (촬영용 아님)
□ ＋ 버튼 → 주식 → 실제로 안 가진 종목 하나 검색
□ 수량 1주, 평단가는 아무 값
□ ★ 손절선을 현재가와 비슷하게 입력
□ 저장
```

**손절선을 현재가 근처로 잡는 게 요령입니다.** "손절 임박"으로 판정돼서 **오늘 화면 맨 위**에 올라옵니다. 그러면 그 카드 하나만 화면에 담고 찍을 수 있고, 아래 실제 종목과 부동산 카드는 프레임에 안 들어옵니다.

**촬영이 끝나면 지우십시오.**

---

# STEP 6 · 30초 테스트 (2분) ★건너뛰지 마십시오

본 촬영 전에 짧게 찍어보고 확인합니다. 이걸 안 하면 **4분을 다 찍고 나서 소리가 들어간 걸 발견합니다.**

```
1) 녹화 시작
2) 앱을 아무렇게나 10초 조작 (화면 몇 번 누르기)
3) 녹화 중지
4) 갤러리에서 재생하고 확인
```

**확인할 것**

```
□ 소리가 안 들어갔는가          ← 들어갔으면 STEP 1-1 소리 설정 다시
□ 터치할 때 동그라미가 보이는가  ← 안 보이면 STEP 2 다시
□ 알림이 안 떴는가
□ 화면색이 일정한가 (라이트 모드 고정)
□ 화질이 또렷한가 (1080p)
□ 글자가 화면 밖으로 안 나가는가
```

마지막 줄도 봐주십시오. 어제 고친 넘침이 실제 폰에서도 잡혔는지 확인하는 자리입니다. **`오늘` 화면에서 "당일 +10.0% 급변"처럼 소수점 한 자리로 나오면** 제대로 배포된 것입니다.

# 준비 완료 체크

```
□ 화면 녹화: 소리 없음 · 1080p
□ 터치 표시 켜짐 (동그라미 확인)
□ 방해금지 · 라이트 모드 고정 · 밝기 최대
□ 촬영용 브라우저 정함 (4-A / 4-B / 4-C)
□ 홈 화면 ONE·HUB 아이콘 삭제
□ 더미 종목 1개 + 손절선 현재가 근처
□ 30초 테스트 6개 항목 통과
```

---

**여기까지 되면 알려주십시오.**

바로 녹화로 넘어가서, **네 덩어리를 하나씩** 같이 찍겠습니다. 한 덩어리씩 찍고 확인하고 다음으로 가는 방식입니다 — 한 번에 4분을 찍으면 한 군데 틀렸을 때 처음부터 다시 해야 합니다.

막히는 줄이 있으면 **그 줄 번호만** 말씀해 주십시오. 기종 이름(갤럭시 S○○ 같은)을 알려주시면 그 기종 메뉴 이름으로 다시 적어드리겠습니다.
