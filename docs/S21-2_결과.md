# S21-2 결과 — ETF "보유 ETF가 없어" 오문구

작업일 2026-09-01 · Claude Code

## 원인
`lib/etfRecommend.js` 폴백(추천 후보 0건, `if (!recs.length)`)이 **보유 유무와 무관하게** "보유 ETF가 없어…"를 반환. 조건은 *추천 없음*인데 문장은 *보유 없음*을 주장 → 7종목·8.51억 보유자에게도 그 문장이 노출.

## 한 것 (`lib/etfRecommend.js`)
폴백을 **보유 건수로 분기**:
- `holdings.length === 0` → 기존 '시작 가이드'("보유 ETF가 없어 …") 유지(맞는 말).
- `holdings.length > 0` → 사실에 맞는 문장: "지금 배분에서 뚜렷한 조정 후보가 없습니다 — 목표 배분을 정하면 더 구체적으로 제안합니다."(name="지금은 뚜렷한 조정 후보 없음", bucket="유지").

`pages/pwa/today.js`·`pages/pwa/etf.js` 는 손대지 않음 — 둘 다 `recommendEtfs` 를 그대로 쓰므로 문구가 자동 반영된다. `grep "보유 ETF가 없어"` → 이제 보유 0 분기 안에만 1건 존재.

## 검증
- `bash scripts/verify_s19.sh` → **FAIL=0**.
- `npm run build`(webpack) → **통과**.
- 합격선(ETF 보유 계정 화면에서 "보유 ETF가 없어" 0건, 보유 0 계정에선 여전히 노출)은 로그인 브라우저 확인.
