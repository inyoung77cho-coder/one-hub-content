작업일 2026-09-01 · Claude Code

## 문제
`clearQuoteCache()` 는 `_cache`·`_inflight` 만 비운다. 비우는 시점에 **이미 날아간 요청**은 그대로 진행되고, 완료되면 `_cache.set(url, 옛값)` 으로 **옛 값을 다시 심는다.** 보유 입력·삭제 직후 30초간 반영 안 된 숫자가 보일 수 있다.

## 한 것 (`lib/quoteCache.js`)
- 모듈 세대 카운터 `let _gen = 0`.
- `clearQuoteCache()` 가 `_gen++` 먼저 수행 후 clear.
- `cachedJson` 진입 시 `const myGen = _gen` 기록, 응답 후 `if (j != null && myGen === _gen) _cache.set(...)` — clear 이후 완료된 옛 요청은 세대 불일치라 캐시에 저장 안 됨(그 요청의 awaiter 에게 값은 반환되지만, 컴포넌트는 `onehub-assets-change` 로 곧 재조회).
