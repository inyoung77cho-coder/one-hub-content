작업일 2026-09-02 · Claude Code

## 한 것 (`pages/pwa/realestate.js` 분석 탭 · 커버리지 확대 없음)
1. **첫 화면을 내 집으로** — 분석 탭 최상단이 결론 한 줄(분기 변화 포함) → **내 단지 포지션(RePositionCard, 대장 대비 위치·평형별 적정가)** 순으로 이미 배치됨. 그 바로 아래 **갈아타기 참고 카드**를 새로 얹어 "내 집" 흐름을 강화.
2. **갈아타기 시뮬레이터(씨앗)** — `lib/moveCost.js`(신규): 취득세·양도세·중개보수 **간이 추정 엔진**. 분석 탭에 "내 집을 지금 팔면" — 예상 매도가 − 중개보수 − 양도세(1주택·2년·12억↓ 비과세) = **손에 쥐는 금액**을 한 카드로. `estimateMoveCost`(목표가까지 포함한 추가 필요자금)도 엔진에 준비(목표 단지 선택 UI는 후속).
3. **분기 리듬 명시** — "📅 부동산은 분기·연 단위로 움직입니다 — 다음 데이터 갱신 {다음 분기 1일}. 매일 볼 화면이 아니에요." 정직한 주기 표시.
4. **커버리지 안 넓힘 · R² 정직 표시 유지** — 기존 태도 보존.
5. **면책** — 거래비용은 간이 추정(누진·감면·중과 미반영), MOVE_COST_DISCLAIMER 상시 표기.
