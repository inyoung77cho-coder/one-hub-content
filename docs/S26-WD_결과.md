## 각 페이지 변경(동일 절차)
1. **font-size 리터럴 → `--fs-1…8` 최근접 토큰** (sed 일괄, CRLF 보존). 매핑은 최근접값 — 대부분 <5% 변화(안전), 아래 큰 반올림만 ⚠️.
2. **border-radius 리터럴 → `--radius-sm/md/card`** 최근접(≤11px→sm, 12–17px→md, ≥18px→card). **999px(완전 원형 pill)은 리터럴 유지** — `--radius-pill` 이 이 페이지 스코프(비-pwa-wrapper)에서 20px 이라 매핑 시 pill 이 깨진다(근거 있는 예외).
3. **탭 → 공용 `SegTabs`**: today `td-seg`(자산·부동산·ETF·이야기 4칸, 배지 유지) / assets `as-stocktabs`(보유·추천 2칸). 죽은 CSS 제거.
   - assets 선택 탭 표시가 **파랑 채움 → 흰 카드 띄움(SegTabs 정본)** 으로 통일됨(의도된 변화).
4. padding 은 이번엔 카드 내부 위주(대량 변경 아님) — 다음 이관에서 계속.

## Card 컴포넌트 이관 — ⚠️ 이번엔 보류(사유 명시)
- `.card` 를 `<Card>` 로 바꾸려면 **각 페이지의 `.card .자식` 후손 셀렉터가 전부 깨진다**(styled-jsx 스코프상 `<Card>` 루트엔 `.card` 클래스가 없어짐). 후손 셀렉터까지 안전하게 재작성하려면 화면 육안 확인이 필수인데, 로그인 게이트로 이 세션에서 확인 불가.
- 따라서 **M3(카드 정의)는 이번 이관에서 손대지 않음**. 무검증 통과 처리하지 않고 명시적으로 남긴다(공통 규칙 "확인 못 한 것은 ⚠️"). Card 부품(S26-4)은 준비돼 있으니, 실기기 QA 가능한 시점에 페이지별로 안전 적용.
