## 배치 HA — 앱이 죽어 보이지 않게 (프론트)

### S33-1 · 백엔드 장애 전역 감지 + 정직한 배너
- **한 것**:
  - `lib/backendHealth.js`(신설) — `BackendHealthProvider` + `useBackendHealth()`. PWA 부팅 시 `/api/health` **1회**만 조회(cachedJson dedup), 결과를 컨텍스트로 전 화면 공유. 반환 `{ ok, down:[...], degraded, checkedAt, loading, reachable }`.
  - `components/BackendHealthBanner.js`(신설) — 하나라도 `up:false`면 상단 한 줄: `지금 최신 정보를 받아오지 못하고 있습니다 — 아래 숫자는 마지막으로 확인한 값입니다.` + `상태 보기 →`(/status 링크). 정상이면 아무것도 안 그림.
  - `_app.js` — 전체를 `BackendHealthProvider`로 감싸고 PWA 라우트에서 `BackendHealthBanner` 렌더(EngineVersionBanner 위).
  - **문구 규칙 준수**: "오류/실패/에러" 안 씀. `/api/health` 자체 미도달(null)이면 거짓 경보 안 띄움(reachable:false, 배너 없음).
- **안 한 것**: 없음.
- **파일**: `lib/backendHealth.js`, `components/BackendHealthBanner.js`, `pages/_app.js`.
- **검증**: `npm run build`(=next build --webpack) 성공. ⚠️ 실제 down 상태 육안은 로그인 게이트라 사용자 몫 — 로직상 `!ok && down.length`일 때만 렌더(정상 조용).

### S33-2 · 마지막으로 본 값을 보여준다 (침묵 금지)
- **한 것**:
  - `lib/lastGood.js`(신설) — `saveLastGood/loadLastGood/agoLabel`. 성공값을 localStorage에 저장, 실패 시 복원 + "N시간 전 기준" 라벨. ★실패를 빈 배열·0으로 위장 안 함.
  - `today.js` 뉴스: `setNews([])`(실패를 '뉴스 없음'으로 위장) 제거 → 성공 시 저장 / 실패 시 **마지막 값 + "N시간 전 기준"** / 마지막 값도 없으면 **"지금 불러오지 못함" 자리표시자**(읽을 거리 헤더 배지 + 펼침 시 재시도 카드).
  - `today.js` 메인 대시보드(`dash`)·원장(`ledger`): 성공 시 저장, 못 받으면 **마지막 값 복원** → `status`를 `ok`(새 값)/`stale`(이전 값 표시)/`error`(둘 다 없음)로 정직하게. `DataState`가 hasData=true면 "이전 데이터 표시" 배너 + 카드를 계속 그림 → **빈 화면 아님**.
- **안 한 것 / 못 한 것**:
  - 보조 피드의 조용한 catch(시황 brief·newsBrief·opNotes·storyComments·regionDelta·re/feed·etf-movers)는 **표(원래 비어도 되는 것)의 3번**에 해당 → 지금처럼 조용히 생략 유지(빈 카드보다 정직한 생략). 실패를 데이터로 위장하는 것은 아님.
  - `index.js`의 개별 catch 전수 교체는 이번에 안 함 — 전역 배너(S33-1)가 index.js 포함 전 PWA 라우트를 덮고, `assets.js`는 이미 올바른 형태(`BACKEND_UNAVAILABLE` 경고). today.js를 최우선으로 완료. index.js 개별 catch는 후속 권장.
- **파일**: `lib/lastGood.js`, `pages/pwa/today.js`.
- **검증**: build 성공. 로직: 전 백엔드 down → 전역 배너 + DataState "이전 데이터 표시"(복원된 마지막 값) 또는 "다시 시도"(마지막 값도 없을 때) + 하단탭. **헤더·하단탭만 남는 빈 화면이 되지 않음.** ⚠️ 실제 육안(로그인 게이트)은 사용자 몫.

### S33-3 · 엔진 배너 문구를 두 가지로 분리
- **한 것**: `EngineVersionBanner.js`에서 **도달 실패(ok:false·catch) 시 아무것도 안 그리게**(setState(null)) 변경 → 도달 실패는 전역 배너(S33-1)가 전담. 이 배너는 **계약 불일치(api_contract) 전용**으로 남김(기존 문구 유지). 과거 "엔진 버전을 확인하지 못했습니다"가 사용자에게 '버전 문제'로 오진·신고를 유발했던 문구 제거.
- **안 한 것**: 계약 불일치 문구는 진짜 버전 문제이므로 그대로.
- **파일**: `components/EngineVersionBanner.js`.
- **검증**: build 성공. 도달 실패 시 전역 배너만, 계약 불일치 시 이 배너만 → **동시에 뜨지 않음**. "엔진 버전을 확인하지 못했습니다" 문구는 코드에서 제거됨.
