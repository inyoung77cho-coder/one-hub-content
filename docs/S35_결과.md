## S35-1 · 반올림 누락 — 한 것

### 파일 / 변경

- **`pages/pwa/today.js:370`** (지시서가 지목한 그 한 줄)
  - 전: `` `당일 ${Number(p.change_1d) >= 0 ? "+" : ""}${Number(p.change_1d)}% 급변` ``
  - 후: `` if (p.change_1d != null) { const d = Number(p.change_1d); return `당일 ${d >= 0 ? "+" : ""}${d.toFixed(1)}% 급변`; } ``
  - `"당일 +10.018214936247727% 급변"`(소수점 15자리, 100%에서 +100px·137%에서 +189px 넘침) → `"당일 +10.0% 급변"`.

### 같은 실수 전수 확인 — 한 것

지시서의 검색(`${Number(...)}%` · `${p.xxx}%`, `toFixed`/`Math.round`/CSS width 제외)을 `pages`·`components`·`lib`에 수행. **정확히 같은 버그(가변 float 를 반올림 없이 텍스트 `%` 로 출력)** 를 두 곳 더 발견 → 수정:

- **`pages/pwa/index.js:2055`** 최근검색 칩 `+${s.change_1d}%` → `+${Number(s.change_1d).toFixed(1)}%`
- **`pages/pwa/index.js:1813`** 근거 배지 `5일 수익률 …${s.change_5d}%` → `…${Number(s.change_5d).toFixed(1)}%`

`change_1d`/`change_5d` 는 `today.js` 버그와 동일 필드이고, 같은 파일의 형제 코드(`vol_ratio.toFixed(1)` 등)가 이미 반올림하므로 명백한 동일 버그로 판단해 함께 고쳤다.
