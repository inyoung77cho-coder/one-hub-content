텔레그램 봇 & 콘텐츠 관리 화면 사용법

부동산·뉴스 콘텐츠가 텔레그램 봇에서 board-admin 화면까지 어떻게 이어지는지, 각 명령어와 버튼이 무엇을 하는지 정리했습니다.

전체 흐름 부동산 봇 뉴스 봇 관리 화면 주의사항
1

전체 흐름

봇 2개(부동산·뉴스)가 콘텐츠를 만들고, board-admin 한 화면에서 두 봇의 결과물과 회원까지 관리합니다.

1
텔레그램 봇에 텍스트·이미지 전송

카톡방 시세 캡처, 뉴스 기사 사진 등을 봇에게 그대로 전달

2
AI가 자동으로 정리

단지·평형·호가·요약(부동산) 또는 헤드라인·요약·분류(뉴스)로 구조화

3
게시 부동산=수동 확인 후 게시뉴스=자동 게시

부동산은 봇 카드에서 "게시" 버튼을 눌러야 화면에 노출되고, 뉴스는 정리되는 즉시 '오늘' 피드에 올라갑니다

4
board-admin에서 확인·수정

내용이 틀렸거나 지워야 하면 여기서 최종 손질

2

🏢 부동산 봇

① 정보 입력

  • 카톡방 시세·시황 텍스트를 붙여넣거나 시세표 이미지를 보내면 AI가 단지·평형·호가·요약으로 정리해 카드로 보여줍니다.
  • 명확한 가격도 없고 의미 있는 시황(시세소식·개발호재)도 아니면 카드 없이 자동 폐기됩니다 — 필요하면 /view로 확인 후 게시 가능.

② 카드 버튼

  • ✅ 게시 — board에 🟡 미검증 표시로 공개
  • ✏️ 수정 — 필드(단지/평형/호가/유형/요약)를 골라 새 값으로 답장
  • 🗑 버림 — 폐기(이미 게시된 것도 다시 누르면 보드에서 내려감)

③ 명령어

명령어내용
/list최근 15건
/list 대기|게시|폐기상태로 필터
/list 오늘|어제|2026-08-01날짜로 필터
/list 이번주|지난주주간(월~일) 필터
/list 전체최근 100건까지
/view <번호>그 항목 카드 다시 보기(버튼으로 게시/수정/버림)
/del <번호>바로 폐기(게시된 것도 즉시 내려감)
/report [일수]최근 수집분 종합 리포트 초안(기본 7일)
/menu · /help메뉴 · 이 도움말

상태+기간 조합도 가능합니다 (예: /list 게시 이번주). 면적은 평 기준, 개인정보·전화번호는 게시 시 자동 제거됩니다.

3

📰 뉴스 봇

부동산 봇과 가장 다른 점 — 뉴스는 확인 버튼 없이 AI가 요약하는 즉시 '오늘' 피드에 자동 게시됩니다. 틀린 내용은 올라간 뒤에 /edit나 board-admin에서 고치는 방식입니다.

① 뉴스 올리기

  • 뉴스 기사나 이미지를 보내면 AI가 요약해 자동 게시됩니다.
  • 해시태그로 분류 가능: #글로벌 #거시 #증시 #부동산 #정책 #시사 (예: "미 증시 사상 최고 #증시")

② 명령어

명령어내용
/list오늘 올라온 뉴스
/list 어제 · /list 2026-08-01날짜로 필터
/pin [번호]상단 고정
/pub [번호]게시
/draft [번호]비공개(초안)로 전환
/del [번호]숨김
/importance <번호> <1~5>중요도 지정
/edit <번호> <새 요약>요약 수정
/help · /menu이 도움말

번호는 /list로 확인합니다. 개인정보·저작권(무단전재) 콘텐츠는 자동 필터링됩니다.

4

⚙️ 관리 화면 (board-admin)

봇이 만든 콘텐츠와 회원을 최종적으로 확인·수정하는 곳입니다. 여기서 바꾸면 공개 화면에 곧바로 반영됩니다. 운영자 계정으로 로그인해야 접근할 수 있습니다.

부동산 신규 정보

봇으로 게시된 매물·시세소식 카드를 목록으로 보고, 단지/평형/호가/유형/요약을 직접 수정하거나 "보드에서 내리기"로 소프트 삭제할 수 있습니다.

리포트

/report로 만든 종합 리포트의 제목·헤드라인·기간 표기·종합 요약을 수정합니다.

뉴스

섹션·중요도·게시 상태(초안/게시됨/내림)·헤드라인·본문을 수정합니다. 뉴스봇이 이미 자동 게시한 내용을 사후 검수하는 주 창구입니다.

회원

가입 회원의 닉네임·카카오 연동·티어·가입일·최근 로그인을 확인하고, 활성화 / 정지 / 탈퇴 처리할 수 있습니다. 운영자 본인 계정은 자기잠금 방지를 위해 상태 변경 버튼이 보이지 않습니다.

5

알아두면 좋은 점

삭제는 대부분 되돌릴 수 있습니다. "보드에서 내리기" · "화면에서 내리기"는 소프트 삭제(hidden 처리)라 완전히 지워지는 게 아니라 화면에서만 감춰집니다. 회원 "탈퇴 처리"도 다시 활성화로 되돌릴 수 있습니다.
봇 명령어는 운영자 텔레그램 계정에서만 동작합니다. 다른 계정이 봇에게 명령을 보내도 응답하지 않습니다.
