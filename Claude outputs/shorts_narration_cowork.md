## 0. 한눈에 (팀 공유용)

- **무엇**: 아파트 "실거래" 통계 도구를 소개하는 30초 세로 숏폼. 지역 커뮤니티·추천 알고리즘 유입 → 무료 도구 체험 → 가입.
- **왜**: 가입 없이 맛보는 입구를 열었고(유입 경로 신설), 유입은 **로그인 밖**에서만 일어남.
- **완성 대본 5편**(실데이터)·**포맷 템플릿 3종**은 같은 폴더 `shorts_estimate.md` 에. 이 문서는 그중 **녹음용 나레이션만** 뽑은 것 + 제작 체크리스트.
- ★**규제선(절대)**: "사라 / 팔아라 / 지금이 기회 / 적정가 / 저평가" 금지. 항상 **"실거래 기반 통계·정보"**.
- ★**녹화 직전** `one-hub.kr/estimate`에서 그 단지를 다시 조회해 **최신 숫자로 교체**(아래 숫자는 2026-09-06 샘플).

## 1. TTS 녹음 설정 (권장)

- **보이스**: 따뜻한 한국어 여성/남성 1인. (edge-tts 예: `ko-KR-SunHiNeural` 여 · `ko-KR-InJoonNeural` 남)
- **속도(rate)**: **+0%**로 녹음(억양 보존) → 빠르게 느껴지면 편집에서 배속. 편당 총 28~30초에 맞추기.
- **문장 사이**: 컷 전환마다 **0.3~0.5초 무음** 삽입(자막·화면과 싱크).
- **숫자 읽기**: 아래 스크립트는 이미 TTS가 읽기 좋은 형태("21억 5천", "플러스 2.4 퍼센트")로 정리됨 — 그대로 붙여넣기.
- **한 편 = 5줄**. 줄 번호 = 컷 순서(0–3 / 3–7 / 7–18 / 18–25 / 25–30초).

## 3. 녹음용 나레이션 — 포맷 템플릿 3종 (단지만 갈아끼워 양산)

`[단지명]`·`[동]`·숫자만 바꾸면 새 단지로 무한 복제됩니다.

### 템플릿 1 · 호기심형 ("우리 아파트 지금 얼마?")
```
1. [동] [단지명], 지금 진짜 얼마에 팔렸을까요?
2. 호가 말고, 실제로 신고된 거래가요.
3. [N]평형은 최근 실거래 중앙값 [금액]. [건수]건이 신고됐네요.
4. 6개월 추이도 한눈에. 최근엔 [올랐고/내렸고]요.
5. 검색만 하면 끝. 로그인도 가입도 필요 없어요.
```

### 템플릿 2 · 차별화형 ("호가 vs 실거래")
```
1. 네이버엔 [호가]에 나와 있는데…
2. 실제로는 얼마에 팔렸을까요?
3. 신고된 실거래는 중앙값 [금액], 최고가도 [금액]. 호가와 차이가 보이죠.
4. 평형마다 값이 다르니까, 내 평형만 콕 집어서.
5. 호가 말고 실거래로 확인하세요. 무료예요.
```

### 템플릿 3 · 관계형 ("부모님 집 시세")
```
1. 부모님이 물어보시는데, 앱 깔라고 하기도 그렇고…
2. 링크 하나면 됩니다. 가입도, 로그인도 없이.
3. 열자마자 단지명만. 평형별 실거래랑 6개월 추이가 딱.
4. 어느 평형이 얼마에, 몇 건 팔렸는지까지요.
5. 부모님께도, 친구에게도 링크 하나면 충분해요.
```

## 4. 화면 녹화 순서 (컷 = 나레이션 줄 번호와 1:1)

1. `one-hub.kr/estimate` 열기 → 지역 칩 선택
2. 단지명 타이핑(자동완성) → **실거래 보기**
3. 결과에서 **평형 칩** 눌러 대상 평형 강조(대표·최고·건수 확대)
4. **6개월 막대 추이**로 스크롤
5. 엔드카드: 화면 위에 `one-hub.kr/estimate · 무료 · 로그인 없음`

- 세로 9:16 · 자막은 상단 1/3(모바일 UI 안 가리게) · 하단 워터마크 `실거래 신고 자료(국토부) 기반 · 로그인 없이 무료`.

## 6. 유입 추적 (자동)

- 모든 링크를 **`?from=youtube`** 로 통일 → 운영자 화면(정비소)에서 **유튜브 조회·가입 전환이 따로 집계**됩니다.
- 다른 채널도 같은 방식: `?from=kakao` · `?from=blog` · `?from=cafe` (코드 수정 불필요, 자동 집계).
- 편별로 나누고 싶으면 편마다 다른 값(`?from=yt1`, `?from=yt2` …)을 써도 됩니다(소문자·영숫자 16자 이내).
