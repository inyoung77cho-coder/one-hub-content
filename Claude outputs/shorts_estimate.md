## 1편 — "우리 아파트, 지금 진짜 얼마?" (호기심 / 실거주·집주인)

**타깃**: 자기 단지 시세가 궁금한 실거주자 · 지역 맘카페
**컨셉**: 검색 한 번 → 실거래가 바로. "네이버 부동산 호가 말고 진짜 팔린 값."

| 초 | 화면 | 자막(상단) | 나레이션(TTS) |
|---|---|---|---|
| 0–3 | 손가락이 폰에 단지명 타이핑(estimate 입력창) | **우리 아파트 지금 얼마?** | "우리 아파트, 지금 진짜 얼마에 팔렸을까요?" |
| 3–7 | 자동완성에서 단지 선택 → '실거래 보기' 탭 | 호가 말고 **진짜 팔린 값** | "호가 말고, 실제로 신고된 거래가요." |
| 7–18 | 결과 화면: 평형 칩 → 대표 13.3억·최고 13.9억·20건 강조 확대 | **19평 대표 13.3억 · 최근 20건** | "예를 들어 시범우성 19평은 최근 실거래 중앙값 13억 3천. 20건이 신고됐네요." |
| 18–25 | 6개월 막대 추이로 스크롤(−6.1% 자막) | **6개월 −6.1%** | "6개월 추이도 한눈에. 최근엔 살짝 내렸고요." |
| 25–30 | 엔드카드(URL) | **로그인 없이 · 무료** | "검색만 하면 끝. 로그인도 가입도 필요 없어요." |

- **BGM/톤**: 밝고 가벼운 로파이. 궁금증→해소.
- **규제 체크**: 숫자는 '실거래 통계'로만 서술. "싸다/비싸다/사라" 없음. ✅

- **해시태그**: `#아파트실거래 #[동이름]아파트 #부동산시세 #실거래가 #원허브`
- **고정 댓글**: `단지명만 넣으면 평형별 실거래·6개월 추이까지 나와요(로그인 X). 👉 one-hub.kr/estimate`

## 2편 — "호가와 실거래, 이렇게 다릅니다" (차별화 / 갭 강조)

**타깃**: 매수·매도 저울질 중인 사람 · 부동산 오픈채팅
**컨셉**: 흔한 통증 — 네이버 호가는 높은데 실제 팔린 값은 다르다. 그 갭을 보여줌.

| 초 | 화면 | 자막(상단) | 나레이션(TTS) |
|---|---|---|---|
| 0–3 | 네이버 부동산 호가 스샷(블러 처리) vs 물음표 | **호가 15억?** | "네이버엔 15억에 나와 있는데…" |
| 3–6 | estimate로 전환·단지 입력 | **그럼 진짜 팔린 값은?** | "실제로는 얼마에 팔렸을까요?" |
| 6–16 | 결과: 대표 실거래·최고 실거래 나란히 강조 | **실거래 중앙값 13.3억 · 최고 13.9억** | "신고된 실거래는 중앙값 13억 3천, 최고가도 13억대. 호가와 차이가 보이죠." |
| 16–24 | 평형 칩 눌러 다른 평형 전환(즉시 갱신) | **평형별로 다 달라요** | "평형마다 값이 다르니까, 내 평형만 콕 집어서." |
| 24–30 | 엔드카드(URL) | **로그인 없이 30초** | "호가 말고 실거래로 확인하세요. 무료예요." |

- **BGM/톤**: 약간의 긴장→해소. '진실 확인' 느낌.
- **규제 체크**: '호가 vs 실거래'는 사실 비교(정보). 가격 판단·권유 없음. 네이버 스샷은 블러+출처 표기 권장. ✅
- **설명란**: `호가와 실거래는 다릅니다. 신고된 실제 거래가를 무료로 확인하세요 👉 https://one-hub.kr/estimate`
- **해시태그**: `#호가vs실거래 #아파트실거래가 #부동산 #[동이름] #원허브`
- **고정 댓글**: `※ 저희는 "적정가"를 매기지 않습니다 — 신고된 실거래 통계만 보여드려요.`

## 3편 공통 마무리 팁

- **출처 파라미터**(선택): 링크를 `one-hub.kr/estimate?from=youtube` 로 달아두면, 다음 스프린트에서 유튜브 유입을 따로 집계할 수 있습니다(현재는 단일 카운터).
- **A/B 테스트**: 같은 단지·같은 결과로 후킹 자막만 3개(1·2·3편) → 어떤 후킹이 잘 도는지 2주 관찰 후 잘 되는 각도를 양산.
- **양산 축**: 1편 포맷을 지역·단지만 바꿔 편당 대량 생산(서현→정자→수내…) → 지역 키워드 SEO 축적.
- **금지 재확인**: 어떤 편에서도 "사라 / 팔아라 / 지금이 기회 / 적정가 / 저평가"를 자막·나레이션·댓글에 쓰지 마세요(유사투자자문 리스크).
